Q1 · Graphical method · in scope

Solve graphically

\[\max\; f = 5x_1 + 7x_2\qquad \text{s.t.}\quad \begin{aligned}[t] &4x_1 + 5x_2 \le 20\\ &2x_1 + 6x_2 \le 24\\ &6x_1 + 4x_2 \le 16\\ &x_1,\,x_2 \ge 0 \end{aligned}\]

Feasible corners

Set each inequality to equality and find the intercepts. On the \(x_2\)-axis all three lines give \(x_2 \le 4\): \(4(0)+5(4)=20\), \(2(0)+6(4)=24\), \(6(0)+4(4)=16\) — so all three boundaries pass through \((0,4)\). On the \(x_1\)-axis the tightest is \(6x_1 \le 16 \Rightarrow x_1 \le 8/3\). The feasible region is the triangle \((0,0),\ (8/3,0),\ (0,4)\).

Evaluate \(f = 5x_1 + 7x_2\)

\((0,0)\!: 0\), \((8/3,0)\!: 40/3 \approx 13.3\), \((0,4)\!: 28\). Optimum \((x_1,x_2) = (0,4)\), \(f^* = 28\).

Level line and degeneracy

\(\nabla f = (5,7)\) points up-and-right; slide \(5x_1+7x_2 = z\) that way and its last contact is \((0,4)\). The scan annotates \(\nabla f = [7;5]\) — that is transposed; for \(f = 5x_1 + 7x_2\) the gradient is \([5;7]\). The answer is unchanged.

\((0,4)\) is degenerate: three constraint lines meet there, not two. Moving along \(2x_1+6x_2 = 24\) would raise \(f\) (\(5x_1+7x_2 = 28 + \tfrac{8}{3}x_1\)) but immediately breaks \(4x_1+5x_2 \le 20\), so that edge is not feasible — an improving direction exists with no improving feasible edge.

Q2 · Simplex · in scope

Solve the Q1 LP by the simplex method

Same LP as Q1. Add slacks \(s_1, s_2, s_3\) to the three \(\le\) rows; start from the all-slack basis.

Which slacks equal 0 at the optimum?

First pivot

With the convention \(z - 5x_1 - 7x_2 = 0\), the most negative reduced cost is \(-7\), so \(x_2\) enters. Ratio test: \(20/5 = 4\), \(24/6 = 4\), \(16/4 = 4\) — a three-way tie, minimum ratio \(4\).

After one pivot

Pivot any tied row (say \(s_1\) leaves). Then \(x_2 = 4 - 0.8x_1 - 0.2s_1\) and \(z = 28 - 0.6x_1 - 1.4s_1\): no reduced cost improves, so the tableau is optimal after 1 pivot, \(z^* = 28\), \((x_1,x_2) = (0,4)\).

Degeneracy

At the optimum \(s_1 = 0\) (non-basic), and the two remaining basic slacks are \(s_2 = 24 - 6(4) = 0\) and \(s_3 = 16 - 4(4) = 0\). Basic variables at zero \(\Rightarrow\) degenerate optimal tableau. All three slacks are zero here.

Q3 · Branch and bound · final-exam scope, not Quiz 1

Solve the integer program by branch and bound

\[\max\; z = 7x_1 + 5x_2\qquad \text{s.t.}\quad \begin{aligned}[t] &4x_1 + 6x_2 \le 18\\ &2x_1 + 6x_2 \le 9\\ &6x_1 + 3x_2 \le 27\\ &x_1,\,x_2 \ge 0,\ \text{integer} \end{aligned}\]

LP relaxation

All three constraints are tight at \((x_1,x_2) = (4.5,\,0)\): \(4(4.5)=18\), \(2(4.5)=9\), \(6(4.5)=27\). Value \(= 7(4.5) = 31.5\). (This relaxation vertex is itself degenerate.)

Branch on \(x_1\) (fractional at \(4.5\))

  • \(x_1 \ge 5\): infeasible — \(6x_1 \le 27\) forces \(x_1 \le 4.5\). Prune.
  • \(x_1 \le 4\): relaxation optimum \((4,\ \tfrac16)\), value \(173/6 \approx 28.83\). Branch on \(x_2\):
    • \(x_2 \le 0\): \((4,0)\), value \(28\), integer → incumbent \(= 28\).
    • \(x_2 \ge 1\): relaxation optimum \((1.5,\,1)\), value \(15.5 < 28\). Prune.

Integer optimum \((x_1,x_2) = (4,0)\), \(z^* = 28\). (The scan leaves the tree unfinished at one node; the branches above are completed in notes/beginner-notes.tex §5.2.)

Q4 · Graphical method · in scope

Solve graphically

\[\max\; z = 200x + 550y\qquad \text{s.t.}\quad \begin{aligned}[t] &100x + 250y \le 5000\\ &x + y \le 50\\ &x,\,y \ge 0 \end{aligned}\]

Feasible region

\(100x + 250y = 5000\) runs through \((50,0)\) and \((0,20)\); \(x + y = 50\) runs through \((50,0)\) and \((0,50)\). The two lines meet at \((50,0)\), so \(x+y \le 50\) never binds elsewhere. The region is the triangle \((0,0),\ (50,0),\ (0,20)\).

Evaluate \(z = 200x + 550y\)

\((0,0)\!: 0\), \((50,0)\!: 10000\), \((0,20)\!: 11000\). Optimum \((x,y) = (0,20)\), \(z^* = 11000\); the level line's last contact is the vertex \((0,20)\).

Q5 · Simplex · in scope

Solve the Q4 LP by the simplex method

Same LP as Q4. Add slacks \(s_1\) to \(100x+250y \le 5000\) and \(s_2\) to \(x+y \le 50\).

First pivot

\(z - 200x - 550y = 0\): most negative is \(-550\), so \(y\) enters. Ratio test: \(5000/250 = 20\) vs \(50/1 = 50\); minimum \(= 20\), so \(s_1\) leaves.

After one pivot

\(y = 20 - 0.4x - 0.004s_1\), and \(z = 11000 - 20x - 2.2s_1\): optimal after 1 pivot. \((x,y) = (0,20)\), \(z^* = 11000\).

Slack

\(s_2 = 50 - (0 + 20) = 30 > 0\): the constraint \(x + y \le 50\) is not binding, so this optimum is non-degenerate (contrast with Q2).
