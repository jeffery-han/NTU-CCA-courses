1 · What an optimisation problem is

Every question in this quiz is one optimisation problem: pick the numbers that do best against a goal, without breaking any limit. Three pieces:

PieceMeaningIn the quiz
Decision variables \(x_1,\dots,x_n\)the quantities you choose"units of product A per week", etc. — define them with units
Objective \(f(x)\)the single number you rank options byprofit to maximise, or cost/time/waste to minimise
Constraintsequations/inequalities every choice must satisfyresource limits, demands, and \(x_j \ge 0\)

A general linear program (LP), written for maximisation:

\[ \max\ z = c^\mathsf{T}x \qquad\text{subject to}\qquad Ax \le b,\qquad x \ge 0. \]

Linear means every variable appears to the first power with a constant coefficient. \(x_1 x_2\), \(x_1^2\), \(\sqrt{x_1}\), \(x_1/x_2\) would make it nonlinear.

Feasible set. The set of \(x\) satisfying every constraint. A number that violates any capacity, demand, or non-negativity condition is not a solution, however good its objective value looks.
Why LP is special. Linear constraints make the feasible set a convex polyhedron, and a bounded LP always has an optimum at a corner (extreme point). That single fact is what both the graphical method and the simplex method exploit.

Source: notes/beginner-notes.tex §1–2, notes/notes.tex §1–2.

2 · Turning words into a linear program

Q1 gives you a paragraph and asks for the model. Follow a fixed recipe so you never freeze:

  1. Name the variables with units. "Let \(x_1\) = number of Standard units built per week." Not "let \(x_1, x_2\) be the products" — that loses a mark.
  2. Write the objective and say max or min. "Maximise \(z = 40x_1 + 30x_2\) (weekly profit, \$)."
  3. One inequality per limit. Each coefficient must mean something physical: hours per unit, kg per unit, the total available.
  4. Add the hidden constraints: \(x_j \ge 0\) always; \(x_j \in \mathbb{Z}\) only if whole objects are forced (and then say so — it becomes an integer LP).
Sign trap. "at most / no more than / cannot exceed / available" → \(\le\). "at least / minimum / must meet / required" → \(\ge\). "exactly" → \(=\).
The "no reason to produce" trap. A pure cost-minimisation with only \(\le\) limits has the trivial optimum \(x = 0\). A real min-cost model needs a demand \(\ge\) row (or an equality) forcing output.

Lab 2 — classify the constraint

For each phrase, pick the inequality it becomes.

Worked formulation (this is the mock's Q1)

"Each Standard earns \$40, each Premium \$30. Every unit needs 1 assembly-hour; 12 available. Testing: 2 h per Standard, 1 h per Premium; 16 available. Maximise profit."

x1 = Standard units/week,  x2 = Premium units/week   (x1, x2 ≥ 0)

maximise   z = 40 x1 + 30 x2
subject to     x1 +   x2 ≤ 12      (assembly hours)
             2 x1 +   x2 ≤ 16      (test-rig hours)

Every "12" and "16" is a total available; every "1" and "2" is a per-unit rate. That is all Q1 asks for, plus the standard-form step in Module 4.

3 · The graphical method

With two variables you can see the answer — and the quiz explicitly says you can use this to check the simplex result.

  1. Turn each constraint into a boundary line (replace \(\le\) with \(=\)) and draw it.
  2. Use a test point (usually the origin) to decide which side each inequality keeps.
  3. The feasible region is the overlap of all kept sides — a polygon.
  4. Draw the objective line \(c^\mathsf{T}x = z\) for one value; slide it in the improving direction until its last contact with the region. That contact is a corner (or an edge).
  5. Evaluate \(z\) at every corner; the best one wins.
Three special outcomes to name on sight:
  • Infeasible — the constraints have no common point.
  • Unbounded — the region runs to infinity in an improving direction, so \(z\) has no finite max.
  • Multiple optima — the objective line is parallel to a binding edge, so every point on that edge is optimal.

Lab 3 — corner evaluation

LP: max z = 40 x1 + 30 x2, s.t. x1 + x2 ≤ 12, 2 x1 + x2 ≤ 16, x1, x2 ≥ 0. The feasible corners are \((0,0)\), \((8,0)\), \((4,8)\), \((0,12)\). Compute \(z\) at each, then reveal.

Where does \((4,8)\) come from?

It is the intersection of the two constraint lines. Solve \(x_1 + x_2 = 12\) and \(2x_1 + x_2 = 16\): subtract to get \(x_1 = 4\), then \(x_2 = 8\). Both slacks are zero there — both resources fully used.

Only feasible corners count. \(2x_1 + x_2 = 16\) meets the \(x_2\)-axis at \((0,16)\), but that violates \(x_1 + x_2 \le 12\), so it is not a corner of the feasible region.

4 · Standard form: slack, surplus, artificial

The simplex method needs equalities, non-negative variables, and a non-negative right-hand side. Convert like this (multiply a row by \(-1\) first if its RHS is negative):

OriginalBecomesNew variable means
\(a_i^\mathsf{T}x \le b_i\)\(a_i^\mathsf{T}x + s_i = b_i,\ s_i \ge 0\)slack — unused amount of resource \(i\)
\(a_i^\mathsf{T}x \ge b_i\)\(a_i^\mathsf{T}x - e_i = b_i,\ e_i \ge 0\)surplus — amount a requirement is exceeded by
\(x_k\) free (any sign)\(x_k = x_k^+ - x_k^-,\ x_k^\pm \ge 0\)split into positive and negative parts
Artificial variables. An \(=\) row, or a \(\ge\) row after adding surplus, has no obvious basic variable to start from. Add an artificial \(a_i \ge 0\) purely to seed the starting basis. It must end at zero — Module 6.
The quiz's easy case. A maximisation with all \(\le\) constraints and \(b \ge 0\) needs slack variables only. No surplus, no artificial, no Big-M. The slacks themselves form the starting basis. Expect this.

Standard form of the mock LP, with the objective written the way Prof. Su Rong does it (\(z - c^\mathsf{T}x = 0\), so the objective coefficients enter the bottom row negated):

z − 40 x1 − 30 x2                 = 0
      x1 +   x2 + s1        = 12
    2 x1 +   x2       + s2  = 16
    x1, x2, s1, s2 ≥ 0

5 · The simplex method

Simplex walks from corner to adjacent corner, each step keeping feasibility and improving \(z\), until no improvement is possible. One step = one pivot.

Prof. Su Rong's rules (Week 2 transcript)

QuestionRule
Which variable enters?any column with a negative bottom-row entry. ("The most negative one is not really critical.")
Which variable leaves?the row with the smallest non-negative ratio \(b_i / a_{ij}\), over rows with \(a_{ij} > 0\) only.
When do we stop?when every bottom-row entry is \(\ge 0\).
What if no ratio is eligible?the entering column has no positive entry → the LP is unbounded.

Reconciling with notes/notes.tex §"The simplex method"

The review note phrases the same rule as "choose the most negative reduced cost to enter; optimal when no reduced cost is negative", and calls it the minimisation convention. Prof. Su Rong writes the identical bottom row as \(z - c^\mathsf{T}x\) and calls it maximisation. They are the same row and the same stopping test — a negative entry means "improvable", all \(\ge 0\) means "done". Only the label differs. Write whichever your working is consistent with, and always run the ratio test.

Why the ratio test?

When \(x_j\) increases from 0, each basic variable \(x_{B_i}\) changes by \(-a_{ij}\,x_j\). The first basic variable to hit zero is the one with the smallest \(b_i / a_{ij}\) (over \(a_{ij} > 0\)). Push past that and a basic variable goes negative — you leave the feasible region. So the min-ratio row is exactly how far you can go.

Guided pivot walker

LP: max z = 50 x1 + 40 x2, s.t. x1 + x2 ≤ 9, 2 x1 + x2 ≤ 14. Standard form adds slacks \(s_1, s_2\); the objective row is \(z - 50x_1 - 40x_2 = 0\). At each tableau, choose the entering variable and the leaving row, then apply the pivot. The tool checks your choice against the rules and follows the most-negative entering default so it can walk one fixed path.

Full worked solution of the walker LP

Tableau 0 basis \(s_1=9, s_2=14\), \(z=0\). Bottom row \((-50,-40,0,0\mid 0)\). Enter \(x_1\); ratios \(9/1=9\), \(14/2=7\) → \(s_2\) leaves.

Tableau 1 \(x_1=7,\ z=350\). Bottom row \((0,-15,0,25\mid 350)\). Enter \(x_2\); ratios \(2/0.5=4\), \(7/0.5=14\) → \(s_1\) leaves.

Tableau 2 bottom row \((0,0,30,10\mid 410)\) — all \(\ge 0\), optimal. \(x_1^\ast = 5,\ x_2^\ast = 4,\ z^\ast = 410\). Graphical check: corners \((7,0)\to350\), \((0,9)\to360\), \((5,4)\to410\). ✓ Shadow prices read off the final row: \(30\) and \(10\).

Common slips. Entering the most positive entry (that is a \(c_j - z_j\) row, not \(z - c^\mathsf{T}x\)); taking the largest ratio; dividing by a zero or negative pivot-column entry in the ratio test; stopping one pivot early because you forgot to re-scan the bottom row.

6 · Two-phase and Big-M (if artificials appear)

You only need this if the LP has an \(=\) or \(\ge\) constraint. The mock does not, but a formulation with a "must meet demand" clause would.

Two-phase method

  1. Phase I: temporarily replace the objective with "minimise the sum of the artificial variables". Run simplex. If the minimum is \(> 0\), the original LP is infeasible — stop.
  2. If the minimum is \(0\), every artificial has left the basis (or is a degenerate zero). Drop the artificial columns and the Phase I row.
  3. Phase II: restore the real objective and continue simplex from the feasible basis you just found.

Big-M method

Add \(+M a_i\) to a minimisation objective (or \(-M a_i\) to a maximisation), with \(M\) a symbolic "very large" number. The penalty forces every \(a_i\) to zero at optimality. Prof. Su Rong's phrasing: the penalty must make the objective worse, so its sign is opposite to what you are optimising.

Sign of the penalty. Maximising → subtract \(Ma_i\). Minimising → add \(Ma_i\). Get this backwards and simplex will happily keep an artificial positive.
Two-phase avoids treating \(M\) as a finite number, which is why the notes and transcript prefer it. Either is acceptable if done consistently.

Source: notes/beginner-notes.tex §6 last paragraph; notes/notes.tex §2.2–2.3.

7 · Duality & sensitivity — the likely add-on

In the Week 2 sensitivity worked example the lecturer says, while perturbing a cost coefficient and an \(A\)-entry, "everybody knows actually in a quiz or in the final exam, how do you operate." This is the in-scope topic most likely to be an extra part. It is nearly free once you have the final tableau.

The primal–dual pair

\[ \min\ c^\mathsf{T}x,\ \ Ax \ge b,\ x \ge 0 \qquad\longleftrightarrow\qquad \max\ b^\mathsf{T}w,\ \ A^\mathsf{T}w \le c,\ w \ge 0. \]

The matrix transposes; primal constraints ↔ dual variables; primal variables ↔ dual constraints; min ↔ max. Strong duality: if one has an optimum, so does the other, with equal objective values.

Complementary slackness

\[ w_i\big((Ax)_i - b_i\big) = 0, \qquad x_j\big(c_j - (A^\mathsf{T}w)_j\big) = 0. \]

A constraint with slack has zero dual value; a variable that is positive makes its dual constraint tight. It is a logical either/or — not permission to divide by something that might be zero.

Reading sensitivity off the final tableau

WantDo
Shadow price of constraint \(i\)read the final bottom-row entry under \(s_i\)
RHS range keeping the basisrequire \(B^{-1}(b + \Delta b) \ge 0\)
Cost-coefficient range (basic \(x_k\))add \(\delta \times\) (the \(x_k\) row) to the bottom row; keep every entry \(\ge 0\)

Worked on the walker LP (max 50x1 + 40x2, opt \((5,4)\), \(z=410\))

Final bottom row \((0,0,30,10\mid 410)\), final \(x_1\) row \((1,0,-1,1\mid 5)\), final \(x_2\) row \((0,1,2,-1\mid 4)\), so \(B^{-1} = \begin{bmatrix}2 & -1\\ -1 & 1\end{bmatrix}\) (rows \(x_2, x_1\); columns \(s_1, s_2\)).

  • Shadow prices: constraint 1 → \(30\), constraint 2 → \(10\). One more unit of resource 1 is worth \(30\) more profit (within range).
  • Dual: \(\min 9w_1 + 14w_2\), \(w_1 + 2w_2 \ge 50\), \(w_1 + w_2 \ge 40\). At \((w_1,w_2)=(30,10)\): both tight (\(50, 40\)), \(9(30)+14(10)=410\) = primal. ✓
  • RHS range for \(b_1 = 9 + \Delta\): \(x_B = B^{-1}(9+\Delta,14)^\mathsf{T} = (4 + 2\Delta,\ 5 - \Delta) \ge 0\) ⇒ \(-2 \le \Delta \le 5\) ⇒ \(b_1 \in [7, 14]\).
  • Cost range for \(c_1 = 50 + \delta\) (\(x_1\) basic, row \((1,0,-1,1)\)): bottom row \(s_1 \to 30 - \delta\), \(s_2 \to 10 + \delta\); both \(\ge 0\) ⇒ \(-10 \le \delta \le 30\) ⇒ \(c_1 \in [40, 80]\).

8 · Legacy topics: transportation & NLP

Open only if you have the core method solid — this is the previous lecturer's format

Through Sep 2025 (a different lecturer) Quiz 1 was Week 5, multiple-choice + fill in the blank, and tested a balanced transportation problem and a constrained NLP. Prof. Su Rong dropped both. Keep them warm in case the coordinator reverts.

Transportation problem

Ship \(x_{ij} \ge 0\) from source \(i\) (supply \(s_i\)) to destination \(j\) (demand \(d_j\)) at cost \(c_{ij}\):

\[ \min \sum_{i,j} c_{ij}x_{ij},\quad \sum_j x_{ij} = s_i,\quad \sum_i x_{ij} = d_j. \]
  1. Balance: if \(\sum s_i \ne \sum d_j\), add a dummy source or destination (zero costs, unless told otherwise) to absorb the difference.
  2. Initial BFS: Vogel's Approximation Method — each round, penalty = (2nd smallest cost) − (smallest cost) along a line; pick the largest penalty; fill its cheapest cell as much as possible; cross out the exhausted row/column. A non-degenerate BFS has \(m + n - 1\) basic cells.
  3. Optimality (MODI): fix \(u_1 = 0\); solve \(u_i + v_j = c_{ij}\) on basic cells; compute \(c_{ij} - u_i - v_j\) on non-basic cells. All \(\ge 0\) → optimal. A negative cell → trace a closed \(+/-\) loop through basic cells and shift the smallest "−" amount.
Fewer than \(m+n-1\) basic cells → degenerate; add a zero allocation in an independent cell before solving potentials.

Full worked example: ../quizzes/quiz-1-prediction.md §L1.

Constrained NLP

For \(\min f(x)\) s.t. \(h(x) = 0\): \(L = f - \lambda h\), set \(\nabla_x L = 0\) with \(h(x)=0\). For inequality constraints \(g_j(x) \ge 0\), the KKT conditions:

\[ \nabla f - \textstyle\sum_j \mu_j \nabla g_j = 0,\quad g_j \ge 0,\quad \mu_j \ge 0,\quad \mu_j g_j = 0. \]
  • An inactive inequality (\(g_j > 0\)) forces \(\mu_j = 0\); an active one (\(g_j = 0\)) may carry \(\mu_j > 0\).
  • Second-order check (this is what "positive-definiteness calculation" meant): at a stationary point, \(H = \nabla^2 f \succ 0\) → strict local min, \(\prec 0\) → max, indefinite → saddle. For an equality-constrained problem use the reduced/bordered Hessian, or substitute the constraint and test the resulting unconstrained Hessian.
The recalled trap: an optimise-the-container question where a poster assumed an open-top box when the problem said closed. Read whether the lid is included before writing the area.

Full worked example (closed box, \(V=32\), cube, bordered-Hessian check): ../quizzes/quiz-1-prediction.md §L2.

Working the MCQs

  1. Formulation / standard-form items. Read units → objective sense → one row per limit → \(x\ge0\); for standard form add a slack per \(\le\) row and write the objective row as \(z - c^\mathsf{T}x = 0\). Count variables vs constraints if it asks which form to graph.
  2. Graphical items. Use the ruler. Draw the lines from their intercepts, shade with a test point, read the corner; slide the value line along the gradient \((c_1,c_2)\) for the optimum. Watch for unbounded / infeasible / multiple-optima pictures.
  3. Simplex-tableau items. Entering = a negative bottom-row entry; leaving = smallest \(b_i/a_{ij}\) over \(a_{ij}>0\) rows only; optimal when the whole bottom row is \(\ge 0\). A ratio-test tie ⇒ the next basis is degenerate.
  4. Sensitivity items. Shadow price of constraint \(i\) = the final bottom-row entry under slack \(s_i\). RHS range: keep \(B^{-1}(b+\Delta b)\ge 0\). Cost-coefficient range: keep the bottom-row signs. These read straight off the given final tableau.

If you get stuck

  • Two answers look plausible: solve the small LP graphically on your draft paper — four corners, two minutes — and see which number it matches.
  • Simplex option "never terminates": that's the unbounded case (no \(a_{ij}>0\) in the entering column).
  • Time left over: re-check every ratio test and every sign in the bottom row — that's where the wrong option is designed to catch you.
