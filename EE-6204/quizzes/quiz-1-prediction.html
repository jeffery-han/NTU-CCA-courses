The problem Q1 + Q2 share it

A workshop assembles two loudspeaker models, Standard and Premium. Each Standard sold earns \$40 profit, each Premium \$30. Every unit of either model needs 1 hour at the shared assembly bench; 12 assembly-hours are available this week. Testing takes 2 hours per Standard and 1 hour per Premium; the test rig has 16 hours available. All output is sold.

How many of each model should be built this week to maximise profit, and what is that profit?

Q1 — Formulation 5 marks

On paper: define the decision variables (with units), write the objective (state max/min), write each constraint, add non-negativity, then convert to standard form for the simplex method (one slack per "\(\leq\)" row; objective row as \(z - c^\mathsf{T}x = 0\)).

Full marks need: variables defined with units; "maximise" stated; both resource constraints; non-negativity; and the standard-form conversion (slacks + \(z-c^\mathsf{T}x=0\) row).

Q2 — Simplex method 11 marks

On paper: build the initial tableau (slack basis, objective row \(z-c^\mathsf{T}x=0\)), then pivot to optimality. Prof. Su Rong's rules (from the Week 2 transcript):

  • Entering: any column with a negative bottom-row entry ("most negative is not really critical").
  • Leaving: the row with the minimum non-negative ratio \(b_i / a_{ij}\), over rows with \(a_{ij} > 0\) only.
  • Stop when every bottom-row entry is \(\geq 0\).
  • A maximization with all "\(\leq\)" constraints needs slack variables only — no surplus, no artificial, no Big-M.
Section S — predicted unseen item: sensitivity & duality (8 marks, not part of the 16)

The Week 2 transcript shows Prof. Su Rong perturbing a cost coefficient (\(c_1 \to c_1 + \theta\)) and an \(A\)-entry while saying "everybody knows … in a quiz or in the final exam, how do you operate". This is the in-scope topic most likely to be the add-on. Work it on the same optimal tableau.

  1. Shadow prices (2). Read the marginal value of one more assembly-hour and one more test-rig hour straight off the final bottom row.
  2. One more unit + dual (2). Predict the new \(z^\ast\) if assembly capacity rises 12 → 13. Form the dual LP and check strong duality / complementary slackness.
  3. RHS ranging (3). Using \(B^{-1}(b + \Delta b) \geq 0\), find the range of each right-hand side over which the current basis stays optimal.
  4. Cost ranging (1). Find the range of \(c_1\) that leaves the optimal basis (and \(x^\ast\)) unchanged.
Section L — legacy block: transportation + constrained NLP (previous lecturer, lower probability)

These are the questions Prof. Su Rong removed. Through Sep 2025 the quiz was Week 5, MCQ + fill-in-blank, Q1 = balanced transportation, Q2 = constrained NLP. Do these only after the core paper; the full statements and worked answers are in quiz-1-prediction.md §L.

  • L1 — Transportation. Supplies \((20,30,25)\), demands \((15,20,20,20)\), the 3×4 cost table in the key. Balance, build an initial BFS by Vogel's Approximation Method, then test optimality with \(u_i + v_j = c_{ij}\) potentials.
  • L2 — Constrained NLP. Least-material closed box of volume \(V = 32\). Minimise surface area subject to \(xyz = 32\) with a Lagrange multiplier, then a second-order check for "minimum". (Watch whether the box has a lid — that was the recalled trap.)
