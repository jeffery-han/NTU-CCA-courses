Outliers: yes, three. Each class is inspected separately, because the three classes have very different ranges (for example, feature C is about 1.5 in class 1 but about 5.5 in class 2). For each class and feature I used Tukey's far-out rule: a value is an outlier if it lies outside

Three methods for missing values

  1. Deletion. Discard every sample that has a missing entry (listwise deletion). This is simple and introduces no invented values, but it loses information and can bias the data if values are not missing at random. It is acceptable here because only 3 of 120 samples are affected.
  2. Mean / median imputation (class-conditional). Replace the missing entry with the mean or median of that feature, computed only over samples of the same class. This keeps the sample but shrinks the feature's variance a little.
  3. Model-based imputation. Predict the missing entry from the other features, e.g. with k-nearest-neighbour imputation (average the feature over the k most similar complete samples) or regression on the observed features. The EM algorithm is a likelihood-based alternative. These use correlations between features (A and C are strongly correlated here), so they give more realistic values.

Three methods for outliers

  1. Detection and removal. Flag values with a statistical rule (z-score beyond ±3, or the IQR fences above) and delete those samples. This is clean when the outliers are clearly errors and few in number.
  2. Capping (winsorising). Replace a value outside the fence with the nearest fence value, or with a chosen percentile (e.g. the 1st/99th). The sample is kept and its influence is limited.
  3. Treat as missing and impute, or use robust estimates. Replace the outlier with the class median or a k-NN estimate, as for a missing value. Alternatively, keep it but estimate parameters with robust statistics (median and MAD instead of mean and standard deviation), so a single extreme value cannot dominate.

(2) Naïve Bayes classifier design

As instructed, the 3 samples with missing values and the 3 outlier samples are removed, which leaves 114 training samples (class 1: 38, class 2: 37, class 3: 39).

Step 1: Bayes decision rule. Assign x = (x1, x2, x3, x4) = (A, B, C, D) to the class with the largest posterior probability

P(ωi | x) = p(x | ωi) P(ωi)p(x),    i = 1, 2, 3.

Because p(x) is the same for every class, it is enough to compare p(x | ωi) P(ωi).

Step 2: Naïve (conditional independence) assumption. Given the class, the four features are assumed independent, so

p(x | ωi) = ∏j=14 p(xj | ωi).

This replaces one 4-dimensional density with four 1-dimensional ones, which is far easier to estimate from 114 samples.

Step 3: Model each feature as Gaussian within each class. The features are continuous measurements, so

p(xj | ωi) = 1√(2π σij2) exp( − (xj − μij)22σij2 ).

Step 4: Estimate the parameters from the training data. Let Ni be the number of class-i samples and N = 114.

P(ωi) = NiN,    μij = 1Ni ∑k ∈ ωi xkj,    σij2 = 1Ni − 1 ∑k ∈ ωi (xkj − μij)2

The unbiased variance (Ni − 1) is used. The maximum-likelihood version (divide by Ni) gives exactly the same 30 test predictions.

Assignment 2

The training set (data_train.mat) has 577 samples with five features x1–x5; label_train.mat gives each sample's class as +1 or −1. There are 301 samples labelled +1 and 276 labelled −1, and no missing values. The test set (data_test.mat) has 23 unlabelled samples. Below, class ω1 means label +1 and class ω2 means label −1.

(1) Fisher linear discriminant classifier

Idea. Fisher's method looks for a direction w such that, after every sample is projected onto it (y = wTx), the two projected class means are far apart while each class's projected samples stay close together. It maximises the Fisher criterion

J(w) = (m̃1 − m̃2)2s̃12 + s̃22 = wTSBwwTSWw,

where m̃i and s̃i2 are the mean and scatter of class i after projection, SB = (m1 − m2)(m1 − m2)T is the between-class scatter matrix, and SW is the within-class scatter matrix defined in Step 2.

Step 1: Class mean vectors. mi = (1/Ni) ∑x ∈ ωi x, with N1 = 301 and N2 = 276:

m1 = (−0.0418, 0.0671, −0.0540, 0.0912, −0.0147)T,    m2 = (1.0428, 2.0623, 0.9408, 1.2551, 1.6047)T
m1 − m2 = (−1.0846, −1.9952, −0.9947, −1.1639, −1.6194)T

SW is clearly non-singular (its diagonal dominates), so it can be inverted directly without regularisation.

Step 3: Weight vector. Setting the gradient of J(w) to zero gives the generalised eigenvalue problem SBw = λSWw. Because SBw always points along m1 − m2, and the length of w does not change the decision, the solution is

w = SW−1(m1 − m2) = 10−3 × (−1.7860, −3.4729, −1.9467, −1.6826, −2.6581)T

The entries are small only because SW is a sum over 577 samples. Scaling w and w0 by the same positive constant gives the same decision. This orientation (m1 − m2) places class ω1 on the positive side of the boundary.

Step 4: Bias term. The boundary is placed so that the midpoint of the two class means lies on it, i.e. g((m1 + m2)/2) = 0:

w0 = −wT m1 + m22 = −(−0.1678) + (−17.2331)2 × 10−3 = 8.7005 × 10−3

(The projected class means are m̃1 = wTm1 = −0.1678 × 10−3 and m̃2 = wTm2 = −17.2331 × 10−3.)

Step 5: Discriminant function and decision rule.

g(x) = wTx + w0 = 10−3 × ( −1.7860 x1 − 3.4729 x2 − 1.9467 x3 − 1.6826 x4 − 2.6581 x5 + 8.7005 )

Decision rule: if g(x) > 0, assign x to ω1 (label +1); if g(x) < 0, assign x to ω2 (label −1). The boundary g(x) = 0 is a hyperplane in the 5-dimensional feature space. On the 577 training samples this classifier is 93.2% correct (13 errors in ω1, 26 in ω2; resubstitution accuracy, an optimistic estimate).

Placing the boundary at the midpoint of the projected means is a convention, not necessarily the optimal threshold. In practice w0 can be tuned on the data (here the errors are uneven, 13 vs 26). None of the test predictions below would change unless w0 moved by more than 3.217 × 10−3, the smallest |g(x)| among the test samples.
