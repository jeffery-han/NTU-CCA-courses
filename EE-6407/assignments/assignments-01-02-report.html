Outliers are there as well, three of them. Each class has to be inspected on its own, because the three classes occupy very different ranges: feature C is about 1.5 in class 1 and about 5.5 in class 2. I screened with Tukey's far-out fence, class by class and feature by feature, so a value is flagged when it falls outside

[ Q1 − 3·IQR ,   Q3 + 3·IQR ],    IQR = Q3 − Q1,

where Q1 and Q3 are that class's lower and upper quartiles of that feature. Quartiles are interpolated linearly between order statistics, the convention of numpy.percentile and statistics.quantiles(method='inclusive'). The data are recorded to one or two decimal places, so the fences are computed in exact decimal arithmetic: a value sitting exactly on a fence should not be flagged because of floating-point noise. The 3·IQR rule is a conservative screening criterion and not a definition of what an outlier is, and the 1.5·IQR variant is discussed below.

The screening runs in a fixed order. The three incomplete rows are set aside first, not imputed and not used in the fence calculation. For each class and each of the four features, Q1, Q3 and the far-out fence are then computed on the remaining rows, every cell outside its fence is flagged, and the union of all rows holding a flagged cell is removed.

Three cells are flagged, in three different rows, so three cells and three samples are removed. The two counts coincide only because no row contains more than one flagged cell:

The other three features of each of these rows sit inside their own fences, so each row is a single-cell anomaly and not a wholly unusual sample. The flagged values are 17 to 20 standard deviations from their class mean, well beyond anything else the class produces. A z-score rule with the same class statistics (|z| > 3) flags exactly the same three cells, so the conclusion does not depend on the rule chosen. Why the entry is wrong cannot be known from the data: a reading 17σ out is consistent with a recording error, but the intended value is unrecoverable, so these rows are dropped rather than corrected.

The milder 1.5·IQR rule flags eight more borderline cells (rows 1, 26, 69, 79, 97, 98, 105, 116), with |z| between 2.12 and 2.98. They sit just outside the usual range for their class, and nothing in the data suggests an error, so I kept them. That is a judgement and not a finding: a different threshold would keep or drop a different set, which is why the threshold and the quartile convention are stated at all.

Three methods can address the missing entries. Listwise deletion drops the incomplete samples; it invents nothing, but it is unbiased only when the values are missing completely at random, which three cells cannot establish. With 3 of 120 samples affected it is defensible here. Class-conditional imputation fills the entry with the mean or median of that feature over samples of the same class; it keeps the sample but shrinks the feature's variance slightly, and it needs a known label, so an unconditional mean would have to be used on the unlabelled test data. Model-based imputation predicts the entry from the other features, by k-NN averaging or by regression on the observed ones, with EM as the likelihood-based alternative; it exploits the correlation between features (A and C, 0.875) but need not recover the true entry.

Three methods can address the outliers. Detection and removal flags values by a rule, a z-score beyond ±3 or the IQR fences above, and deletes those samples; it works when the outliers are few and evidently wrong, and it is what I applied here. Capping, or winsorising, replaces a value outside the fence with the nearest fence value or with a chosen percentile such as the 1st or 99th, keeping the sample but limiting its influence. The outlier can also be treated as missing and imputed (class median or k-NN), or kept while the parameters are estimated with robust statistics (median and MAD), so one extreme value cannot dominate the fit.

(2) Naïve Bayes classifier design

As instructed, the 3 samples with missing values and the 3 outlier samples are removed, which leaves 114 training samples (class 1: 38, class 2: 37, class 3: 39).

Each sample is a point x = (x1, x2, x3, x4) = (A, B, C, D), and the Bayes decision rule assigns it to the class with the largest posterior probability

P(ωi | x) = p(x | ωi) P(ωi)p(x),    i = 1, 2, 3.

Because p(x) is the same for every class, it is enough to compare p(x | ωi) P(ωi).

Naïve Bayes then assumes that, given the class, the four features are independent, so

p(x | ωi) = ∏j=14 p(xj | ωi).

This replaces one 4-dimensional density with four 1-dimensional ones, far easier to estimate from 114 samples. It is an approximation: A and C correlate at 0.875 overall, and at 0.33, 0.89 and 0.74 within the three classes, so the joint density is not a product of marginals. The classifier can still be accurate, because a decision only needs the ranking of the three scores.

The features are continuous, so each one needs a density within each class. I took the Gaussian form because a mean and a variance per class-feature pair specify it completely. Continuity alone does not make a variable Gaussian, and no normality check is made here:

p(xj | ωi) = 1√(2π σij2) exp( − (xj − μij)22σij2 ).

With Ni the number of class-i samples and N = 114, the parameters are estimated as

P(ωi) = Ni / N,
μij = (1 / Ni) ∑k ∈ ωi xkj,
σij2 = (1 / (Ni − 1)) ∑k ∈ ωi (xkj − μij)2.

The unbiased variance (Ni − 1) is used.

The term ½·4·ln 2π = 3.6758 is the same for all three classes, so it shifts the scores but never the ranking. The worked example below gives the score both with and without it.

The rule is to assign x to ωk where k = arg maxi gi(x), with a tie broken towards the smaller class index (no test sample ties). Each gi is quadratic in x with a diagonal covariance matrix, so the decision boundaries are quadratic surfaces in four dimensions. The training set (data_train.mat) has 577 samples with five features x1–x5; label_train.mat gives each sample's class as +1 or −1. (1) Fisher linear discriminant classifier

Fisher's method looks for a direction w such that, once every sample is projected onto it (y = wTx), the two projected class means are far apart while each class's projected samples stay close together. It maximises the Fisher criterion

J(w) = (m̃1 − m̃2)2s̃12 + s̃22 = wTSBwwTSWw,

where m̃i is the projected class mean, s̃i2 = ∑y ∈ ωi (y − m̃i)2 is the projected within-class scatter (a sum of squares, not divided by a count), SB = (m1 − m2)(m1 − m2)T is the between-class scatter matrix, and SW is the within-class scatter matrix defined below.

The class mean vectors are mi = (1/Ni) ∑x ∈ ωi x, with N1 = 301 and N2 = 276:

m1 = (−0.0418, 0.0671, −0.0540, 0.0912, −0.0147)T,
m2 = (1.0428, 2.0623, 0.9408, 1.2551, 1.6047)T,
m1 − m2 = (−1.0846, −1.9952, −0.9947, −1.1639, −1.6194)T.

The within-class scatter of each class is Si = ∑x ∈ ωi (x − mi)(x − mi)T, again a scatter and not divided by Ni, and SW = S1 + S2:

SW is non-singular, being strongly diagonally dominant, so the system SWw = m1 − m2 has a unique solution and can be solved directly. The script does that by Gaussian elimination, without forming an explicit inverse.

Setting the gradient of J(w) to zero gives the generalised eigenvalue problem SBw = λSWw. Because SBw always points along m1 − m2, and the length of w does not change the decision, the solution is

w = SW−1(m1 − m2) = 10−3 × (−1.7860, −3.4729, −1.9467, −1.6826, −2.6581)T.

The entries are small only because SW is a sum over 577 samples; scaling w and w0 by the same positive constant gives the same decision. This orientation (m1 − m2) places class ω1 on the positive side of the boundary. At this w, J(w) = 0.0171: the projected means are m̃1 = −0.168 × 10−3 and m̃2 = −17.233 × 10−3 (8.53 × 10−3 either side of the boundary), and the projected within-class standard deviations are 5.19 × 10−3 and 5.72 × 10−3. The second class is the more spread out after projection, which is consistent with its larger share of the training errors (26 against 13).

Fisher's criterion fixes only the direction, so the bias is a separate convention. The one I used puts the boundary through the midpoint of the two class means, i.e. g((m1 + m2)/2) = 0:

w0 = −wT m1 + m22 = −(−0.1678) + (−17.2331)2 × 10−3 = 8.7005 × 10−3.

The midpoint assumes equal priors and equal misclassification costs. It is a choice rather than a tuned threshold: tuning the bias on the training data could shrink the 26 errors against 13, and nothing here is tuned on the test set.

Weights and bias together then give the discriminant function

g(x) = wTx + w0
    = 10−3 × ( −1.7860 x1 − 3.4729 x2 − 1.9467 x3 − 1.6826 x4 − 2.6581 x5 + 8.7005 ).

If g(x) > 0 the sample goes to ω1 (label +1), otherwise to ω2 (label −1), so an exact tie g(x) = 0 falls to ω2. The boundary g(x) = 0 is a hyperplane in the 5-dimensional feature space. On the 577 training samples the classifier is 93.2% correct:
