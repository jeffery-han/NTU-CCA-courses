Outliers: yes, three. Each class is inspected separately, because the three classes occupy very different ranges (for example, feature C is about 1.5 in class 1 but about 5.5 in class 2). The screening rule is Tukey's far-out fence, applied per class and per feature: a value is flagged if it lies outside

[ Q1 − 3·IQR ,   Q3 + 3·IQR ],    IQR = Q3 − Q1,

where Q1 and Q3 are that class's lower and upper quartiles of that feature. Quartiles use linear interpolation between order statistics (the convention of numpy.percentile and statistics.quantiles(method='inclusive')); since the data are recorded to one or two decimal places, the fences are computed in exact decimal arithmetic so that a value sitting on a fence is not flagged by floating-point noise. The 3·IQR rule is a conservative screening criterion, not a definition of what an outlier is; the 1.5·IQR variant is discussed below. The procedure is applied in a fixed order:

  1. set the three incomplete rows aside (they are neither imputed nor used in the fence calculation);
  2. for each class and each of the four features, compute Q1, Q3 and the far-out fence on the remaining rows;
  3. flag every cell outside its fence;
  4. remove the union of all rows containing a flagged cell.

Three cells are flagged, in three different rows, so three cells and three samples are removed. The two counts coincide only because no row contains more than one flagged cell:

What cannot be established from the data is the cause: a value 17σ out is consistent with a recording or data-entry error, but the intended value is not recoverable, so these rows are removed rather than corrected. Removal is a modelling decision, not a claim about what the true entry was.

The milder 1.5·IQR rule flags eight further borderline cells (rows 1, 26, 69, 79, 97, 98, 105, 116), whose |z| values run from 2.12 to 2.98. They sit just outside the usual range of their class, and nothing in the data indicates an error, so they are kept. This is a judgement rather than a finding: a different threshold would keep or drop a different set, which is why the threshold and the quartile convention are both stated.

Three methods for missing values

  1. Deletion. Discard every sample that has a missing entry (listwise deletion). This is simple and introduces no invented values, but it loses information, and it is unbiased only if the values are missing completely at random — a condition that three missing cells cannot establish. It is defensible here because only 3 of 120 samples are affected.
  2. Mean / median imputation (class-conditional). Replace the missing entry with the mean or median of that feature, computed only over samples of the same class. This keeps the sample but shrinks the feature's variance a little. It requires a known class label, so it applies to labelled training data; for the unlabelled test set an unconditional mean would have to be used instead.
  3. Model-based imputation. Predict the missing entry from the other features, e.g. by k-nearest-neighbour imputation (average the feature over the k most similar complete samples) or by regression on the observed features; the EM algorithm is a likelihood-based alternative. These methods exploit correlations between features — A and C correlate at 0.875 here — so they can reproduce the joint pattern of the data, though not necessarily recover the true entry.

Three methods for outliers

  1. Detection and removal. Flag values with a statistical rule (z-score beyond ±3, or the IQR fences above) and delete those samples. This works well when the outliers are few and evidently erroneous; it is the rule applied here.
  2. Capping (winsorising). Replace a value outside the fence with the nearest fence value, or with a chosen percentile (e.g. the 1st/99th). The sample stays in the data, but its influence is limited.
  3. Treat as missing and impute, or use robust estimates. Replace the outlier with the class median or a k-NN estimate, as for a missing value. Alternatively keep it and estimate parameters with robust statistics (median and MAD instead of mean and standard deviation), so a single extreme value cannot dominate the fit.

(2) Naïve Bayes classifier design

As instructed, the 3 samples with missing values and the 3 outlier samples are removed, which leaves 114 training samples (class 1: 38, class 2: 37, class 3: 39).

Step 1: Bayes decision rule. Assign x = (x1, x2, x3, x4) = (A, B, C, D) to the class with the largest posterior probability

P(ωi | x) = p(x | ωi) P(ωi)p(x),    i = 1, 2, 3.

Because p(x) is the same for every class, it is enough to compare p(x | ωi) P(ωi).

Step 2: Naïve (conditional independence) assumption. Given the class, the four features are assumed independent, so

p(x | ωi) = ∏j=14 p(xj | ωi).

This replaces one 4-dimensional density with four 1-dimensional ones, which are much easier to estimate from 114 samples. It is an approximation, not a property of the data: A and C correlate at 0.875 overall (0.33, 0.89 and 0.74 within the three classes), so the true joint density is not a product of marginals. The classifier can still be accurate, because a decision only needs the correct ranking of the three class scores, not calibrated densities — and it is, at 95.6% resubstitution accuracy below.

Step 3: Model each feature as Gaussian within each class. The features are continuous, so a density model is needed; the Gaussian form is a modelling assumption chosen because it is fully specified by a mean and a variance per class-feature pair. Continuity alone does not make a variable Gaussian, and no normality check is attempted here:

p(xj | ωi) = 1√(2π σij2) exp( − (xj − μij)22σij2 ).

Step 4: Estimate the parameters from the training data. Let Ni be the number of class-i samples and N = 114.

P(ωi) = Ni / N,
μij = (1 / Ni) ∑k ∈ ωi xkj,
σij2 = (1 / (Ni − 1)) ∑k ∈ ωi (xkj − μij)2.

The unbiased variance (Ni − 1) is used. The maximum-likelihood version (divide by Ni) gives exactly the same 30 test predictions, as the script's assertion checks, so the choice affects no reported result.

Step 5: Discriminant function. Taking the natural logarithm of p(x | ωi) P(ωi) turns the product into a sum without changing which class is largest:

gi(x) = ln P(ωi) − ∑j=14 [ ½ ln(2πσij2) + (xj − μij)22σij2 ],    i = 1, 2, 3.

Many textbook presentations drop the term ½·4·ln 2π = 3.6758, which is identical for all three classes. Call that reduced discriminant g̃i(x) = ln P(ωi) − ½∑j [ ln σij2 + (xj − μij)2/σij2 ]. Then g̃i = gi + 3.6758 for every x, so the two forms always rank the classes identically; only the printed numbers differ.

Decision rule: assign x to ωk where k = arg maxi gi(x); a tie is broken towards the smaller class index (no test sample ties). Each gi is quadratic in x with a diagonal covariance matrix, so the decision boundaries are quadratic surfaces in four dimensions. Assignment 2

The training set (data_train.mat) has 577 samples with five features x1–x5; label_train.mat gives each sample's class as +1 or −1. There are 301 samples labelled +1 and 276 labelled −1, and no missing values. The test set (data_test.mat) has 23 unlabelled samples. Below, class ω1 means label +1 and class ω2 means label −1.

(1) Fisher linear discriminant classifier

Idea. Fisher's method looks for a direction w such that, after every sample is projected onto it (y = wTx), the two projected class means are far apart while each class's projected samples stay close together. It maximises the Fisher criterion

J(w) = (m̃1 − m̃2)2s̃12 + s̃22 = wTSBwwTSWw,

where m̃i is the projected class mean, s̃i2 = ∑y ∈ ωi (y − m̃i)2 is the projected within-class scatter (a sum of squares, not divided by a count), SB = (m1 − m2)(m1 − m2)T is the between-class scatter matrix, and SW is the within-class scatter matrix defined in Step 2.

Step 1: Class mean vectors. mi = (1/Ni) ∑x ∈ ωi x, with N1 = 301 and N2 = 276:

m1 = (−0.0418, 0.0671, −0.0540, 0.0912, −0.0147)T,
m2 = (1.0428, 2.0623, 0.9408, 1.2551, 1.6047)T,
m1 − m2 = (−1.0846, −1.9952, −0.9947, −1.1639, −1.6194)T.

Step 2: Within-class scatter matrix. For each class, Si = ∑x ∈ ωi (x − mi)(x − mi)T (a scatter, i.e. not divided by Ni), and SW = S1 + S2:

SW is non-singular (it is strongly diagonally dominant), so the system SWw = m1 − m2 has a unique solution and can be solved directly — by Gaussian elimination in the script, without forming an explicit inverse.

Step 3: Weight vector. Setting the gradient of J(w) to zero gives the generalised eigenvalue problem SBw = λSWw. Because SBw always points along m1 − m2, and the length of w does not change the decision, the solution is

w = SW−1(m1 − m2) = 10−3 × (−1.7860, −3.4729, −1.9467, −1.6826, −2.6581)T.

The entries are small only because SW is a sum over 577 samples. Scaling w and w0 by the same positive constant gives the same decision; Table 10 lists the same direction under three common scalings. This orientation (m1 − m2) places class ω1 on the positive side of the boundary. At this w, J(w) = 0.0171: the projected means are m̃1 = −0.168 × 10−3 and m̃2 = −17.233 × 10−3 (8.53 × 10−3 either side of the boundary), and the projected within-class standard deviations are 5.19 × 10−3 and 5.72 × 10−3. The second class is the more spread out after projection, which is consistent with its larger share of the training errors (26 against 13).

Step 4: Bias term. Fisher's criterion fixes only the direction; the bias is a separate convention. The one used here places the boundary so that the midpoint of the two class means lies on it, i.e. g((m1 + m2)/2) = 0:

w0 = −wT m1 + m22 = −(−0.1678) + (−17.2331)2 × 10−3 = 8.7005 × 10−3.

The midpoint convention is equivalent to assuming equal priors and equal misclassification costs under the shared-covariance Gaussian reading of Fisher's method; the empirical class counts do not by themselves force a prior correction. Method notes, limitations, and reproducibility

  • Comparison of the two classifiers. Both are linear in their parameters on the log scale, but they assume different things: Naïve Bayes models each feature separately with its own variance per class and produces quadratic boundaries, while Fisher's method uses one shared within-class scatter and produces a single hyperplane. Their training accuracies (95.6% and 93.2%) are not directly comparable — different data, different numbers of classes and features — and both are resubstitution figures. The leave-one-out values, 94.7% and 93.1%, are the fairer summaries.
  • Assumptions that are not tested here. The Gaussian form of Assignment 1 is a modelling choice, not a verified property; no normality test was run. Conditional independence is demonstrably violated (A and C correlate at 0.875), yet the classifier remains accurate because only the ranking of the scores matters. Fisher's method assumes the two classes share a within-class scatter matrix; the projected standard deviations (5.19 and 5.72 × 10−3) suggest this is reasonable but not exact.
  • What the numbers do not say. Neither accuracy figure estimates performance on the test sets, for which no labels exist. The cleaning decisions of Assignment 1 (which rows to remove) were made once, on all 120 rows, before the leave-one-out loop, so that figure is slightly optimistic; a fully nested procedure would re-derive the fences inside every fold. No threshold, variance, or parameter was tuned on any test sample.
  • Reproducibility. python3 -I assignment-01-naive-bayes.py and python3 -I assignment-02-fisher-lda.py, run in EE-6407/assignments/, regenerate every table entry above and rewrite Figures 1 and 2 between their FIG1/FIG2 markers in this file. Both scripts use only the Python standard library plus the two small readers xlsx_reader.py and mat_reader.py, and both carry assertions for the counts, parameters, and predictions quoted here, so a change in the data or in any modelling decision fails loudly rather than silently disagreeing with the report.
