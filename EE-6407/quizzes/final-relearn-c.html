1 · TSP tour length from a permutation Fix Mock C −4.5

Start here: read the chromosome left to right, then go home

In the TSP coding used in this course, a chromosome is the visiting order: \(1\,3\,5\,2\,6\,4\) means “start at city 1, then go to 3, then 5, 2, 6, 4, then return to 1”. With \(n\) cities a closed tour has \(n\) edges:

\[ L = d(g_1,g_2)+d(g_2,g_3)+\dots+d(g_{n-1},g_n)+\underbrace{d(g_n,g_1)}_{\text{return edge}}. \]

What you did in Mock C: you read gene \(i\) as “the position at which city \(i\) is visited”. For \(P_1=1\,3\,5\,2\,6\,4\) that gives the tour \(1\,4\,2\,6\,3\,5\), which is a different tour. You also left out the return edge. Both errors came from not rereading the question’s sentence “the order in which the cities are visited … returns from the last city to the first”.

Habit: before adding anything, write the tour as a chain of arrows, 1→3→5→2→6→4→1, and count the arrows: there must be \(n\) of them. Then read each \(d\) from the matrix row of the first city and the column of the second.

Worked example

Five cities, rows: [0,4,6,3,7], [4,0,5,8,2], [6,5,0,4,9], [3,8,4,0,5], [7,2,9,5,0]. Chromosome \(3\,1\,5\,2\,4\).
  1. Chain: 3→1→5→2→4→3, which is 5 arrows for 5 cities. ✓
  2. \(d(3,1)=6\), \(d(1,5)=7\), \(d(5,2)=2\), \(d(2,4)=8\), \(d(4,3)=4\). \(L=27\), \(f=100/27=3.7037\).
  3. Traps: without the return edge you get 23; reading genes as positions gives the tour 2 4 1 5 3 and 32.

Your turn

2 · Davies–Bouldin: δ is a root-mean-square Fix Mock C −2.5

Start here: square, average, then one square root

The spread of cluster \(i\) in DB (clustering-evaluation slides pp. 11–12) is

\[ \delta_i=\sqrt{\frac1{n_i}\sum_{\mathbf x\in D_i}\lVert\mathbf x-\mathbf m_i\rVert^2}. \]

The order is square → average → root. The average of the plain distances (what you did) is always a little smaller unless every point is equally far from the centroid. That is why your \(\delta_2\) was right (D and E are equally far from their centroid) and your \(\delta_1\) was wrong.

Then \(S_{12}=(\delta_1+\delta_2)/d(\mathbf m_1,\mathbf m_2)\). Both spreads go on top; in Mock C you used only \(\delta_2\). With two clusters, \(DB=S_{12}\). Lower is better.

Shortcut: \(\sum\lVert\mathbf x-\mathbf m_i\rVert^2\) is the same \(C_i\) that Calinski–Harabasz needs (module 3), so compute it once and reuse it.

3 · Calinski–Harabasz Revision list Mock C −3

Start here: between-cluster over within-cluster, all squared

CH asks how far the clusters sit from the overall centre compared with how spread out they are inside (clustering-evaluation slides pp. 13–15). Higher is better.

\[ CH=\frac{\sum_i n_i\,\lVert\mathbf m_i-\mathbf m\rVert^2}{\sum_i C_i},\qquad C_i=\sum_{\mathbf x\in D_i}\lVert\mathbf x-\mathbf m_i\rVert^2,\qquad \mathbf m=\text{mean of all }N\text{ samples}. \]
\(\mathbf m\)global centroid: average all samples, not the cluster centroids (with unequal \(n_i\) these differ)
\(n_i\lVert\mathbf m_i-\mathbf m\rVert^2\)separation of cluster \(i\), squared and weighted by its size
\(C_i\)cohesion of cluster \(i\): the same sum of squares as in DB

This is the course form: it has no \((N-K)/(K-1)\) factor. In Mock C you set up the top with plain norms \(\lVert\mathbf m_i-\mathbf m\rVert\) and stopped there. Square them, then divide by \(C_1+C_2\).

  3. Top \(=3(9.4222)+2(21.2)=70.6667\). Bottom \(=C_1+C_2=13.3333+2=15.3333\).
  4. \(CH=4.6087\).
