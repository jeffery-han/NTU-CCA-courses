Recall = Sensitivity = TPR = TP / (TP + FN) ← actual + row Precision = TP / (TP + FP) ← predicted + column Specificity = TN / (TN + FP) ← actual − row FPR = FP / (FP + TN) = 1 − specificity Accuracy = (TP + TN) / N, error = 1 − accuracy F1 = 2·P·R / (P + R) (harmonic mean)
  • Recall asks: of the real positives, how many did I catch?
  • Precision asks: when I say “positive”, how often am I right?
  • A rate that divides by one actual row (recall, specificity) depends only on that class. So it doesn't move when the other class gets bigger.
  • Precision, accuracy and F1 mix both actual rows, so they do change when the class balance changes.
Your slip: precision and recall were swapped, and specificity was left out. Write the denominator first, in words: “recall: out of the actual positives”. Then fill in the numbers. Memory hook: Recall = Row, Precision = Predicted.
Class-count change: the classifier stays the same, so doubling the actual negatives doubles FP and TN. Recall stays the same, and so does specificity (TN/(TN+FP) keeps its ratio). Precision falls, because FP grows while TP doesn't. Accuracy moves toward specificity.

Recall's denominator is…

Recall walks along the actual-positive row: TP + FN. Predicted positives (TP + FP) belong to precision.

TP = 8, FP = 2, FN = 8. What is the precision?

Precision = 8 / (8 + 2) = 0.8. If you picked 0.5, that's recall, 8 / (8 + 8). It's the same swap as in Mock C.

Same classifier, but the new test set has twice as many actual negatives. Which metric stays the same?

TN and FP both double, so TN/(TN+FP) keeps its value. Recall doesn't move either, because the positive row is untouched. The other three all involve FP or TN together with TP.

True or false: doubling the actual negatives lowers precision (assume FP > 0). Say why before you tap.

True. TP stays put while FP doubles, so TP/(TP+FP) shrinks.

Screening for a dangerous disease, where missing a sick patient is the costly mistake. Which metric do you most want high?

A missed patient is a false negative. High recall means few FN.

A spam filter, where sending a real email to spam is the costly mistake. Which metric matters most?

A real email flagged as spam is a false positive. Precision punishes FP.

True or false: on a dataset that is 99% negative, accuracy is a good single measure of a classifier.

False. A model that always answers “negative” scores 99% accuracy and has zero recall. Report recall, precision and F1 as well.

Leave-one-out cross-validation on 50 samples trains how many models?

One model per left-out sample, so N = 50. (Stratified k-fold keeps the class proportions the same in every fold. An ROC curve plots TPR against FPR as the threshold changes, and AUC = 0.5 means random guessing.)

Week 10

Decision trees and impurity

Gini = 1 − Σ pₖ² two-class max 0.5 Entropy = −Σ pₖ log₂ pₖ two-class max 1 Misclassific. = 1 − maxₖ pₖ two-class max 0.5 Pure node: all three = 0 Weighted child = (n_L/n)·I_L + (n_R/n)·I_R Impurity drop = I_parent − weighted child
  • Pick the split with the largest drop, which is the same as the smallest weighted child impurity.
  • The question tells you which impurity measure to use (lecturer, Week 10).
  • For a continuous feature, sort the values and try the midpoints between neighbours as thresholds.
  • Gain ratio divides the gain by the split's own entropy. That stops it from favouring features with many values, such as an ID number.
  • Random forest = bootstrap samples + a random feature subset at each split + a majority vote. The randomness makes the trees less alike, which reduces variance.
Your slip: weighted Gini had to be shown to you in Train. Weight each child by its sample count. A plain average of the two children is wrong whenever the child sizes differ.

What is the Gini of a node holding 5 class-A and 5 class-B samples?

1 − (0.5² + 0.5²) = 1 − 0.5 = 0.5. That is the worst case for two classes. Entropy here would be 1.

A split sends 8 samples left (Gini 0.5) and 2 samples right (Gini 0). What is the weighted child Gini?

(8/10)·0.5 + (2/10)·0 = 0.4. The 0.25 answer is the plain-average trap: it treats a 2-sample child as if it counted as much as an 8-sample one.

Parent Gini 0.48, weighted child Gini 0.30. What is the impurity drop?

Drop = parent − weighted children = 0.48 − 0.30 = 0.18. A good split makes this positive and large.

Plain information gain is biased toward which kind of feature?

Splitting on an ID gives pure one-sample leaves and maximal gain, yet it tells you nothing. Gain ratio corrects for this.

True or false: for a feature with sorted values 2, 4, 7, the candidate thresholds are 3 and 5.5.

True. They are the midpoints between neighbouring sorted values.

Besides bootstrapping, what makes the trees in a random forest differ from one another?

Random feature subsets at each split make the trees less alike, so averaging their votes cuts more variance.

Week 12

Feature selection and peaking

Fisher ratio (one feature, two classes): FDR = (m₁ − m₂)² / (σ₁² + σ₂²) larger FDR → better class separation
  • Filter: score features with a separability measure (Fisher ratio, Mahalanobis distance, tr(SW⁻¹SB), mutual information). It is fast and doesn't depend on any classifier.
  • Wrapper: train the actual classifier on each candidate subset and score its accuracy. It is slower, but tuned to that classifier.
  • Search: exhaustive search tries 2d subsets. SFS starts empty and adds the best feature each step. SBS starts with every feature and removes the one whose loss hurts least. SFS can't take a feature back out once added (the nesting effect).

Peaking phenomenon

Keep the number of training samples N fixed and add features. Accuracy first rises, peaks, then falls. Each extra feature adds parameters to estimate (means, variances, covariances) from the same N samples. Those estimates become unreliable, so the classifier gets worse. The conclusion is to select a small, informative feature subset, or to collect more data, which moves the peak to the right.

Your slips: the Fisher ratios were right, but you never wrote the final ranking. End with an explicit order such as “x₂ > x₄ > x₁ > x₃”. Also, if the question gives σ (standard deviation), square it before you add.

Class means 0 and 3, standard deviations σ₁ = 1 and σ₂ = 2. What is the Fisher ratio?

3² / (1² + 2²) = 9/5 = 1.8. Picking 3 means you added σ's instead of variances (9/3). That was the trap in Mock C Q3.

Fisher ratios: x₁ = 0.8, x₂ = 2.5, x₃ = 0.1, x₄ = 1.6. Using a scalar filter, which two features do you keep?

Ranking: x₂ > x₄ > x₁ > x₃. Keep the top two. In the quiz, write that full ranking line.

With fixed N, why does accuracy eventually drop as you add features?

That is the core of peaking. The features may well be useful; what fails is estimating more parameters from limited data.

True or false: with more training samples, the peak moves to a larger number of features.

True. More data means each parameter is estimated reliably, so you can afford more features before it hurts.

Which approach retrains the classifier for every candidate subset?

A wrapper puts the classifier inside the search loop. Filters never train it.

SFS on 4 features. How many single-feature subsets does the first step compare?

It tries each feature on its own: 4 candidates. Step 2 then tries the 3 remaining features added to the winner.

Say it out loud: explain peaking in three sentences
  • With fixed N, adding features first improves and then worsens performance.
  • Each feature adds parameters estimated from the same N samples, so the estimates grow unreliable and the classifier overfits.
  • So select a small set of discriminative features, or get more samples.

Weeks 12–13

Clustering

k-means

  • Assign: compute each point's distance to every centroid and send the point to the nearest one.
  • Update: each centroid becomes the mean of its members, coordinate by coordinate. Update all centroids.
  • Repeat until no point changes cluster.
  • SSE = Σ over clusters Σ over members ‖x − c‖², using squared Euclidean distance to the point's own centroid.
  • The result depends on the initial centroids (a local minimum). You must choose k in advance (plot SSE against k and look for the elbow), and the method prefers round, similar-sized clusters.
squared distance (x,y)→(a,b) = (x−a)² + (y−b)² Manhattan = |x−a| + |y−b|
Your slips: one written comparison used the same centroid on both sides. Always write both distances, d(P, c₁) and d(P, c₂). Point C's squared distance was written as 3 when it was 4. Square each difference, then add.

Hierarchical (HAC), DBSCAN, silhouette

  • HAC: start with every point as its own cluster and repeatedly merge the closest pair. Single linkage uses the minimum pairwise distance, which tends to chain clusters together. Complete uses the maximum, which gives compact clusters. Average uses the mean. Cut the dendrogram to get k clusters.
  • DBSCAN takes eps and MinPts. A core point has at least MinPts neighbours within eps. A border point is within eps of a core point but isn't core itself. Everything else is noise. It needs no k and finds clusters of any shape.
  • Silhouette s = (b − a) / max(a, b). Here a = mean distance to the point's own cluster and b = mean distance to the nearest other cluster. Near 1 is good, near 0 sits on a boundary, and a negative value means the point is probably in the wrong cluster.

1-D k-means, centroids at 1 and 6. Where does the point 4 go?

|4 − 1| = 3 and |4 − 6| = 2, so it goes to 6. Write both numbers in the quiz.

A cluster holds (0,0), (2,4) and (4,2). What is its new centroid?

x: (0+2+4)/3 = 2. y: (0+4+2)/3 = 2. Average each coordinate separately.

Squared Euclidean distance from (1,1) to (3,1)?

(3−1)² + (1−1)² = 4 + 0 = 4. The plain distance is 2. SSE uses the squared value.

SSE in k-means measures…

Only the point's own centroid counts. A lower SSE means tighter clusters.

True or false: k-means always reaches the lowest possible SSE.

False. It converges to a local minimum that depends on the initial centroids. That's why people rerun it with several starts.

1-D clusters {1, 2} and {6, 9}. What is the single-linkage distance?

The closest pair is 2 and 6, giving 4. Complete linkage would take the farthest pair, 1 and 9, giving 8.

True or false: single linkage tends to form long, chained clusters.

True. A single close pair is enough to merge two clusters, so clusters grow like a chain.

Which method needs no k, handles odd shapes and labels outliers as noise?

DBSCAN grows clusters from dense core points. Points that are not core and not near a core point become noise.

A point has a = 2 (own cluster) and b = 6 (nearest other cluster). What is its silhouette?

(6 − 2) / max(2, 6) = 4/6 ≈ 0.67. That's well clustered.

Manhattan distance from (1,2) to (4,6)?

|4−1| + |6−2| = 3 + 4 = 7. The Euclidean distance would be 5.

Say it out loud: one k-means iteration in four steps
  • For every point, write its distance to each centroid.
  • Assign it to the smaller distance.
  • Recompute every centroid as the coordinate-wise mean.
  • If any point changed cluster, repeat. Otherwise stop, and report the final centroids and SSE.

Weeks 6–9 · fast recap

Bayes, LDA, SVM, data prep

  • Bayes rule: choose the class with the largest P(ω)·p(x|ω). Dividing by p(x) rescales every class equally, so it never changes the winner.
  • Naive Bayes: assumes the features are independent given the class, so you multiply the per-feature probabilities. A zero count wipes out the whole product, so use Laplace smoothing (n + 1)/(N + k).
  • Fisher LDA: w = SW⁻¹(m₁ − m₂), w₀ = −½ wᵀ(m₁ + m₂). Check which sign means class 1 by evaluating g(m₁). The closed form is what you use with no computer (Week 8).
  • SVM: margin = 2/‖w‖, w = Σ αᵢdᵢxᵢ. Compute b = dᵢ − wᵀxᵢ, averaged only over support vectors with 0 < α < C. If α = C, the point is inside the margin or misclassified. A larger C allows less slack and gives a narrower margin. The lecturer said computing b “often” appears in exams (Week 9).
  • Data prep: the types are nominal, ordinal, interval and ratio. Fill a missing nominal value with the mode. Box-plot fences sit at Q₁ − 1.5·IQR and Q₃ + 1.5·IQR. Scale with min–max or z-score.

Which support vectors do you average over to compute b?

Only these lie exactly on the margin, where d(wᵀx + b) = 1. Points with α = C have slack, and points with α = 0 aren't support vectors.

w = (3, 4). What is the margin width?

‖w‖ = 5 (a 3-4-5 triangle), so the width is 2/5 = 0.4.

True or false: in a Bayes decision, dividing by the evidence p(x) can change which class wins.

False. Every class is divided by the same p(x), so their order stays the same.

In naive Bayes, one feature value never appears in class B's training data. What do you do?

Without smoothing that zero makes class B's whole product zero, no matter what the other features say.

After computing LDA's g(x) = wᵀx + w₀, how do you know which sign means class 1?

Class 1's mean must land on class 1's side, so the sign of g(m₁) tells you which side that is.

True or false: raising C in a soft-margin SVM tends to give a narrower margin with fewer violations.

True. C is the price of slack. A high C means slack is expensive, so the boundary bends to fit the training points.

Last stop

At the door: eight traps

  • Write the denominator in words first. Recall = row, precision = predicted column.
  • Class balance changes: recall and specificity hold; precision, accuracy and F1 move.
  • Gini split: weight each child by its sample count, then compute parent − weighted children.
  • Fisher: square σ, and finish with an explicit ranking line.
  • k-means: distance to every centroid, update every centroid, finish the SSE.
  • SVM b: only from 0 < α < C, then average.
  • LDA: check the sign with g(m₁).
  • Peaking: fixed N, more parameters, unreliable estimates, so select features.
