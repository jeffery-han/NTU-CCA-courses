Q1 · every paper

Genetic algorithms

Binary decode x = a + (b − a) · dec / (2ᴸ − 1) Roulette pᵢ = fᵢ / Σf Whole arith. child = α·x + (1 − α)·y Blend BLX-α I = |x − y|, child in [min − αI, max + αI] TSP length L = d(g₁,g₂) + … + d(gₙ,g₁) ← n edges Fitness f = 100 / L (shorter tour = fitter)
  • PMX: copy P₁’s segment. For each P₂ segment value v not yet placed: look at P₁ at v’s slot, find that value in P₂, go to its slot; free → put v, occupied → repeat. Fill the rest from P₂.
  • Cycle crossover: follow A → B’s value at that slot → where it sits in A → … until you return. Children take cycles alternately; every gene keeps a position it had in a parent.
  • Inversion (reverse a segment) changes only 2 edges of a tour, so it keeps most adjacency.
  • Exploration searches new areas (mutation, low selection pressure); exploitation refines good ones (high selection pressure, elitism).
Your slips: Mock B filled PMX in order (that is order-1 crossover). Mock C read the chromosome as “position of each city” and dropped the return edge. Write the arrow chain 1→3→5→…→1 first.

3-bit string 101 on [0, 14]. Decoded x?

101 = 5, and 2³ − 1 = 7, so x = 0 + 14·5/7 = 10. Dividing by 2³ = 8 gives 8.75, the classic slip.

Fitnesses 2, 3, 5. Roulette probability of the third?

5 / (2 + 3 + 5) = 0.5. Check that the three probabilities sum to 1 (0.2 + 0.3 + 0.5).

Tour chromosome 2 1 4 3. Which sum is its length?

2→1→4→3→2: four cities, four edges, including the return d(3,2). (a) is the open tour; (d) reads the genes as positions, your Mock C slip.

Whole arithmetic, child = αx + (1 − α)y, with α = 0.25, x = 4, y = 8. Child?

0.25·4 + 0.75·8 = 1 + 6 = 7. The other child swaps the roles: 0.25·8 + 0.75·4 = 5.

PMX: P₁ = 1 2 3 4 5, P₂ = 3 5 1 2 4, copy positions 2–3 from P₁. Child?

Copy _ 2 3 _ _. 5 (slot 2): P₁ has 2 there; 2 is in slot 4 of P₂, which is free, so 5 → slot 4. 1 (slot 3): P₁ has 3; 3 is in slot 1 of P₂, which is free, so 1 → slot 1. Slot 5 from P₂: 4. Child 1 2 3 5 4. (a) is the order-fill trap.

A bigger tournament size mainly increases…

The best of a larger group wins more often, so good individuals dominate faster: more exploitation, less diversity.

Q2 · naive Bayes every paper

Bayes and naive Bayes

Decide largest P(ωⱼ) · p(x | ωⱼ) Gaussian NB, per feature: p(xₖ|ω) = 1/(√(2π)·σ) · exp(−(xₖ − μ)² / (2σ²)) gⱼ = ln P(ωⱼ) − ½Σ ln σ² − ½Σ (x − μ)²/σ² Posterior (2 classes) = 1 / (1 + e^(g₂ − g₁)) Multinomial + Laplace: P(w|c) = (count of w in c + 1) / (n_c + d) n_c = tokens in class c, d = vocabulary of ALL training docs
  • Naive = a product of 1-D bell curves. No covariance matrix, no inverse.
  • Papers usually give σ² (the variance): square-root it for the front factor, use it directly in the exponent.
  • Multinomial: multiply once per token, so a repeated word counts twice.
  • End with a decision line: “… → class X”.
Your slips: Mock B computed P(class | word) instead of P(word | class), and wrote the full Gaussian with C and C⁻¹ swapped. Mock C had the right scores but no final class written.

A class has 6 tokens, the vocabulary has d = 4 words, and “cat” appears 2 times. P(cat | class)?

(2 + 1)/(6 + 4) = 3/10. 0.375 = 3/8 forgets to add d; 0.333 = 2/6 has no smoothing.

Test message “cat cat dog”. How many times is P(cat | c) multiplied into the score?

Once per token, so twice. In Mock B’s worked example this flipped the decision.

One Gaussian feature with σ² = 4 and x − μ = 2. The exponent is…

−(x − μ)²/(2σ²) = −4/8 = −0.5. −1 forgets the 2 (or divides by 2σ with σ = 2).

g₁ − g₂ = ln 3. What is P(ω₁ | x)?

1/(1 + e^(g₂ − g₁)) = 1/(1 + 1/3) = 3/4. Equivalently, the odds are 3 : 1.

True or false: Gaussian naive Bayes needs the inverse of the covariance matrix.

False. Independence means a diagonal covariance, so the density is a product of 1-D Gaussians. The full C⁻¹ belongs to the Gaussian Bayes rule.

Q2 · “you will be instructed” which measure

Decision trees

Gini (course) i = ½ (1 − Σ pⱼ²) pure 0, 50/50 0.25 Entropy i = −Σ pⱼ log₂ pⱼ pure 0, 50/50 1 Split weighted = Σ (n_child / n) · i(child) Decrease Δi = i(parent) − weighted → pick the largest
  • A pure branch does not guarantee the best split; compare the weighted totals.
  • Bagging: trees on bootstrap samples, then vote; this reduces variance. Random forest: bagging plus a random subset of features at each split.
Your slip: Mock B wrote ½Σ(1 − p)², which equals ½Σp², a purity measure. Anchor: a 50/50 node must give 0.25.

Node with 3 (+) and 1 (−). Course Gini?

½(1 − 9/16 − 1/16) = ½ · 6/16 = 3/16. 0.375 forgets the ½; 0.3125 = ½Σp² is your Mock B slip.

10 samples split into 4 (pure) and 6 (Gini 0.25). Weighted Gini?

0.4·0 + 0.6·0.25 = 0.15. 0.125 is the unweighted average of the two children.

What does a random forest add on top of bagging?

The random feature subsets decorrelate the trees, so averaging them cuts more variance.

Q3 · given the αs, just bookkeeping

Soft-margin SVM

Check Σ αᵢ dᵢ = 0 w = Σ αᵢ dᵢ xᵢ (every α > 0) b = avg of dᵢ − wᵀxᵢ over 0 < α < C ONLY margin = 2/‖w‖, half-margin 1/‖w‖ slack ξ = max(0, 1 − d·(wᵀx + b)) new x sign of g = wᵀx + b, distance |g|/‖w‖
  • Why only 0 < α < C for b: KKT gives ξ = 0 there, so the point lies exactly on its margin, d(wᵀx + b) = 1. Points with α = C may lie inside the margin.
  • Where a point is: ξ = 0 on or outside its margin; 0 < ξ < 1 inside the margin, correct side; ξ = 1 on the boundary; ξ > 1 misclassified.
Your slips: Mock B left this blank. Mock C had w and b right, but gave no reason for the samples, wrote ξ = d − g, and slipped on g(1.2, 0.9). Write the reason sentence and use the 1 − d·g form.

C = 1. Support vectors have α = 0.3, 1 and 1. Which gives b?

0 < 0.3 < C, so that point is on its margin. α = C points may be inside it; “if you use all the support vectors you get wrong results” (the lecturer).

w = (3, 4). Margin width?

‖w‖ = 5, so 2/5 = 0.4. 0.2 is the half-margin, 1/‖w‖.

w = (1, 0), b = −2. Sample x = (2.5, 7) with d = −1. Slack ξ?

g = 0.5, so ξ = 1 − (−1)(0.5) = 1.5 > 1: misclassified. Your d − g form gives −1.5, which is impossible.

A training point has ξ = 0.4. Where is it?

0 < ξ < 1: it has crossed its margin line but not the boundary.

Positive αs are 0.5 and 0.5. Negative αs are 0.2 and α₄. What is α₄?

Σαd = 0 means Σα over the positives equals Σα over the negatives: 1 = 0.2 + α₄.

Q3 · computed by hand

Fisher LDA

J(w) = wᵀS_B w / wᵀS_W w S_B = (m₁ − m₂)(m₁ − m₂)ᵀ S_W = S₁ + S₂, Sᵢ = Σ (x − mᵢ)(x − mᵢ)ᵀ w = S_W⁻¹ (m₁ − m₂) w₀ = −wᵀ(m₁ + m₂)/2 g = wᵀx + w₀ > 0 → ω₁ 2×2 inverse: [a b; c d]⁻¹ = 1/(ad − bc) · [d −b; −c a]
  • What maximising J achieves: the projection direction where the class means are farthest apart relative to the spread inside each class.
  • Check w: S_W w must equal m₁ − m₂. Four products catch an arithmetic slip.
  • Confidence: compare |g(x)|/‖w‖ with a class mean’s distance to the boundary, |g(m₁)|/‖w‖. “Less than 1” means nothing.
Your slips: Mock B used “distance < 1” as a yardstick. Mock C had w₁ = 0.118 instead of 0.1039 (the check would have caught it) and left out Sᵢ.

S_W = diag(2, 4), m₁ − m₂ = (4, 4). Fisher w?

The inverse of a diagonal matrix divides each entry: (4/2, 4/4) = (2, 1). (8, 16) multiplies by S_W instead of its inverse.

w = (2, 1), m₁ = (3, 1), m₂ = (1, 1). w₀?

m₁ + m₂ = (4, 2), wᵀ(4, 2) = 10, so w₀ = −10/2 = −5. The boundary passes through the midpoint (2, 1): g = 4 + 1 − 5 = 0. ✓

S_W = [2 1; 1 2], m₁ − m₂ = (3, 3). Someone claims w = (1, 1). Correct?

Check S_W w = (2 + 1, 1 + 2) = (3, 3) = m₁ − m₂. ✓ No inverse needed.

x is 0.3 from the boundary; m₁ is 3 from it. Confidence?

Judge against the class mean’s distance to the boundary. x is close to the boundary, so the decision has low confidence.

Q4 · run by hand

k-means, HAC, DBSCAN

  • k-means: assign each point to its nearest centroid, recompute the means, repeat until nothing moves.
  • HAC: Euclidean = √(Δx² + Δy²); take the root before filling the matrix. Show the matrix after every merge. Dendrogram heights = merge distances, to scale.
  • Linkage: single = closest pair; complete = farthest pair; average = mean of all cross pairs.
  • DBSCAN: core point = enough neighbours within ε; border = within ε of a core point but not core itself; noise = neither. The slides disagree: p. 61 says “at least” MinPts, p. 63 says “more than”. Write the reading you use.
  • GMM/EM: soft k-means. The E-step gives each point a responsibility per cluster; the M-step re-estimates the means, covariances and weights.
Your slip: Mock B used squared distances (with one unsquared entry), so the first merge and every height were wrong. Fixed in Mock C.

1-D points 0, 2, 10, 12; start centroids 0 and 2. Centroids after one k-means update?

0 → c₁; 2, 10 and 12 are nearer 2, so → c₂. The new means are 0 and 24/3 = 8. A second round would give 1 and 11.

On a line: {1, 2} and {6, 9}. Complete-linkage distance?

Farthest pair: 9 − 1 = 8. Single linkage = 6 − 2 = 4; average = (5 + 8 + 4 + 7)/4 = 6.

True or false: (0, 0) and (3, 4) merge at height 25.

False. The height is √25 = 5. Squared distances keep the single-link order but give wrong heights.

DBSCAN: a point has too few neighbours, but lies within ε of a core point. It is…

Border: it belongs to the core point’s cluster but cannot expand it.

Wider range

OLS w = (XᵀX)⁻¹ Xᵀy Ridge w = (XᵀX + λI)⁻¹ Xᵀy L2: shrinks, never 0 Lasso L1 penalty: some weights become exactly 0 Prec. TP / (TP + FP) Recall TP / (TP + FN) F1 2PR / (P + R) z-score (x − μ)/σ min-max (x − min)/(max − min)
  • Evaluation: holdout; k-fold (k models); leave-one-out (n models).
  • Curse of dimensionality: data become sparse and distances lose contrast as dimensions grow. Selection keeps original features (SFS adds, SBS removes); extraction builds new ones (PCA, LDA).
  • Recall matters when misses are costly (disease screening); precision when false alarms are costly (spam).

Which regression can set coefficients exactly to zero (built-in feature selection)?

The L1 penalty’s corners pin weights at 0. Ridge (L2) only shrinks them.

TP = 6, FP = 2, FN = 6. Precision?

6/(6 + 2). Recall would be 6/(6 + 6) = 0.5.

Min-max normalise x = 7 on a feature ranging 2 to 12.

(7 − 2)/(12 − 2) = 0.5.

x = 13, μ = 10, σ = 2. z-score?

(13 − 10)/2 = 1.5.

Leave-one-out on 20 samples trains how many models?

One model per left-out sample: n = 20, each trained on 19.

Last minute

At the door: 12 things to write correctly

  1. TSP: chromosome = visiting order; n edges, return edge included.
  2. PMX follows the mapping chain; it never fills in order.
  3. Binary decoding divides by 2ᴸ − 1.
  4. Laplace: (count + 1)/(n_c + d), with d = the whole training vocabulary; one factor per token.
  5. Gaussian NB: σ² in the exponent with the 2; √(2π)·σ in front.
  6. Gini = ½(1 − Σp²): a 50/50 node gives 0.25.
  7. SVM b: only 0 < α < C, averaged, plus the reason sentence. ξ = 1 − d·g, plus where the point lies.
  8. Fisher: check S_W w = m₁ − m₂; w₀ = −wᵀ(m₁ + m₂)/2; judge confidence against a mean’s distance to the boundary.
  9. HAC: take the √ first; matrix after every merge; heights to scale.
  10. DB δ: square, average, root; both δ go on top.
  11. CH: everything squared, nᵢ weights, no (N−K)/(K−1).
  12. End every classifier part with “→ class X”; carry 4 decimal places.
