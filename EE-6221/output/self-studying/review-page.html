Coordinate frames and rotation matrices

${}^{A}p={}^{A}R_{B}\,{}^{B}p$; columns of ${}^{A}R_{B}$ = axes of $\{B\}$ in $\{A\}$. Proper rotation: $R^{\mathsf T}R=I$, $R^{-1}=R^{\mathsf T}$, $\det R=+1$. Know $R_x,R_y,R_z$ cold ($R_y$ minus sign is bottom-left). Fixed-axis rotation ⇒ premultiply; mobile/body-axis rotation ⇒ postmultiply. $R=[r_1\,r_2\,r_3]$ = normal, sliding, approach; tool advances along $r_3$. Recover angles with atan2, never $\arctan$.

Homogeneous transformations, composition, and inversion

${}^{A}T_{B}=\begin{bmatrix}{}^{A}R_{B}&{}^{A}p_{B}\\0&1\end{bmatrix}$, $p_B$ = origin of $\{B\}$ in $\{A\}$. Compose by inner-label cancellation: ${}^{A}T_{C}={}^{A}T_{B}\,{}^{B}T_{C}$. Inverse: $T^{-1}=\begin{bmatrix}R^{\mathsf T}&-R^{\mathsf T}p\\0&1\end{bmatrix}$ — rotate AND negate the translation. Fixed-frame op premultiplies, current-frame op postmultiplies. Check: rotation block orthonormal, translation in length units.

Direct kinematics and the D–H algorithm

Arm matrix ${}^{0}T_{n}(q)={}^{0}T_{1}\cdots{}^{n-1}T_{n}$; top-left $3\times3$ = orientation, last column = position. D–H: $z_{k-1}$ = joint $k$ axis; $x_k$ = common normal $z_{k-1}\to z_k$. Params $\theta_k$ (about $z_{k-1}$), $d_k$ (along $z_{k-1}$), $a_k$ (along $x_k$, fixed), $\alpha_k$ (about $x_k$, fixed). Revolute ⇒ $\theta_k$ variable; prismatic ⇒ $d_k$ variable; exactly one per joint. Link transform template with $c_k,s_k,c_{\alpha k},s_{\alpha k}$ — memorise it. Workflow: axes → common normals → table → template → multiply in order. 2R: $x=a_1c_1+a_2c_{12}$, $y=a_1s_1+a_2s_{12}$, orientation $=q_1+q_2$. Tool config vector $w=[\,p;\ e^{q_n/\pi}r_3\,]$.

Inverse kinematics

IK: given $(R_d,p_d)$ find $q$ with ${}^{0}T_{n}(q)=[R_d\,p_d;0\,1]$. Not matrix inversion; many-to-one. Check reachability, orientation freedom, joint limits first. Branches: elbow-up/down — $\pm\arccos$ signals a two-branch choice. Analytic (per-robot, exact, all branches) vs numerical (general, needs guess + convergence). Key tool: from $\rho\sin\phi=Y,\ \rho\cos\phi=X$ take $\phi=\operatorname{atan2}(Y,X)$ — correct quadrant, safe at $X=0$. Pattern: decouple base first ($q_1=\operatorname{atan2}(w_2,w_1)$), carry as known, peel next; $\pm$ at elbow: $q_3=\pm\arccos\frac{\lVert b\rVert^2-a_2^2-a_3^2}{2a_2a_3}$. Never $\arctan$; $\arccos$ only gives $[0,\pi]$.

Trajectory planning: path vs trajectory and cubic interpolation

Path = spatial curve $\Gamma$; trajectory = $w(t)=\Gamma(s(t))$, $s:[0,T]\to[0,1]$, $\dot s$ = speed profile. Pick-and-place: pick → lift-off → place → set-down; lift-off $R_{\text{lift}}=R_{\text{pick}}$, $p_{\text{lift}}=p_{\text{pick}}-v\,r_3$ (retreat along $-r_3$). Cubic $w(t)=at^3+bt^2+ct+d$ on $[0,T]$ with $w(0),\dot w(0),w(T),\dot w(T)$: $d=w_0$, $c=v_0$, $a=\frac{2(w_0-w_1)+T(v_0+v_1)}{T^3}$, $b=\frac{3(w_1-w_0)-T(2v_0+v_1)}{T^2}$. Rest-to-rest: $a=-2\Delta/T^3$, $b=3\Delta/T^2$, peak speed $1.5\,\Delta/T$ at $T/2$. Chain segments with continuous velocity AND acceleration.

Robot sensors: classification, fusion, characteristics and errors

Internal (proprioceptive: encoders, potentiometers, tachometers, gyros) vs external (exteroceptive: vision, range, touch). GPS = both (lecturer); p. 17 vs table conflict for compass. Active emits (ultrasonic, laser, IR, beacons, Doppler); passive receives (camera, potentiometer, gyro). Fusion advantages: redundancy (accuracy + reliability), complementarity (new features), timeliness, cost. Accuracy $=1-|m-v|/v$; precision = range/σ (repeatability). Systematic = modellable → calibrate; random = probabilistic → filter/fuse. Encoders/IMU/gyros drift because integration accumulates error → correct with GPS/magnetometer. TOF: $d=ct$ (round trip), object distance $ct/2$; ultrasonic cone 20–70°; dynamic range in dB $=10\log_{10}(\max/\min)$.

Vision sensors and the pinhole camera model

Imaging loses depth and size: every point on a ray hits the same pixel (fundamental drawback). $\bar m=[x,y,z]^{\mathsf T}$ → $m=[x/z,y/z,1]^{\mathsf T}$ → $p=Am$, $A=\begin{bmatrix}f\sigma_x&-f\sigma_x\tan\alpha&u_0\\0&f\sigma_y\sec\alpha&v_0\\0&0&1\end{bmatrix}$, $\alpha\approx0$. $m=A^{-1}p$ is recoverable; $\bar m=zm$ is not without extra information. Extrinsic $[R\ T]$ maps world → camera. Calibration: known target, many images, solve intrinsics + distortion. Radial distortion = straight lines curve (systematic → calibrate). CCD: less noise, more sensitive; CMOS: less power, cheaper. Camera is passive.

Structure and pose from two views: essential matrix and homography

Rigid body: $\bar m_j=R\bar m_j^*+x$. Essential: $m_j^{\mathsf T}Em_j^*=0$, $E=[x]_\times R$ (premultiply by $[x]_\times$ then $m_j^{\mathsf T}$). Homogeneous ⇒ up to scale. 8-point: $Me=0$, ≥8 points, not all coplanar, $x\ne0$; project to $\mathrm{diag}\{\sigma,\sigma,0\}$; 2 solutions × $\pm E$ = 4, positive depth keeps 1. Homography: $H=R+\tfrac{x}{d^*}n^{*\mathsf T}$, $m_j=\alpha_jHm_j^*$, $\alpha_j=z_j^*/z_j$; ≥4 coplanar non-collinear points (8 unknowns, 2 equations each). SVD cases: all equal = pure rotation; two equal = along normal; distinct = 4 → 2 by positive depth → 1 by third view or prior $n^*$. Output: $R$, $x/d^*$, $n^*$; metric if $d^*$ known. H more accurate (lecturer).

Expectation, variance and covariance for sensor fusion

$E(X)=\sum x_iP(x_i)$ or $\int xp(x)dx$; $E[f(X)]=\sum f(x_i)P(x_i)$. $V(X)=E[(X-EX)^2]=E[X^2]-(EX)^2$; zero mean: $V=E[X^2]$. $\mathrm{Cov}=E[XY]-EXEY$. Independent ⇒ uncorrelated (not conversely). Uncorrelated: $V(aX+bY)=a^2V(X)+b^2V(Y)$ — signs vanish, constants square. Weighted average $\sum w_ix_i/\sum w_i$ is simple; KF is statistically optimal at similar cost.

Kalman filter and multi-sensor fusion

Model $x^+=\Phi x+Bu+Gw$, $z=Hx+v$; $w,v$ white Gaussian, covariances $Q,R$. Update $\hat x(t|t)=\hat x(t|t-1)+K[z-H\hat x(t|t-1)]$, $K=PH^{\mathsf T}(HPH^{\mathsf T}+R)^{-1}$, $P(t|t)=(I-KH)P(t|t-1)$; predict $\hat x^+=\Phi\hat x+Bu$, $P^+=\Phi P\Phi^{\mathsf T}+GQG^{\mathsf T}$. Scalar predictor: $P^+=(A-KH)^2P+Q+K^2R$ → $K=AHP/(H^2P+R)$, $P^+=A^2PR/(H^2P+R)+Q$. $R\to\infty\Rightarrow K\to0$. Two sensors, constant $x$: batch $P^+=(1-K_1-K_2)^2P+K_1^2\sigma_1^2+K_2^2\sigma_2^2$, $K_1\propto P\sigma_2^2$, $K_2\propto P\sigma_1^2$. Sequential: $\hat x=\frac{\sigma_2^2z_1+\sigma_1^2z_2}{\sigma_1^2+\sigma_2^2}$, $P=\frac{\sigma_1^2\sigma_2^2}{\sigma_1^2+\sigma_2^2}<\min\sigma_i^2$, $1/P=\sum1/\sigma_i^2$. Optimal only if linear + Gaussian; bias is not removed.
