Question 1 — D–H modelling of an articulated robot (12 marks)

Figure 1 shows an articulated (RRR) robot — the classic waist / shoulder / elbow arm. It has three revolute joints:

  • Joint 1 — the waist: rotates the whole arm about the fixed vertical column axis; joint angle \(\theta_1\).
  • Joint 2 — the shoulder: its axis is horizontal and intersects the column axis, at height \(d_1\) above the base; joint angle \(\theta_2\).
  • Joint 3 — the elbow: its axis is horizontal and parallel to the shoulder axis, a distance \(a_2\) out along link 2; joint angle \(\theta_3\).

Link 3 runs a distance \(a_3\) from the elbow to the wrist point, and a rigid tool of length \(L_t\) continues in the same direction as link 3. Take \(x_0\) as any fixed horizontal reference direction. D–H frame assignments are not unique — any internally consistent choice that yields the correct physical tool pose earns full marks.

  1. (a) Assign a coordinate frame to each link and draw the link-coordinate diagram. Show every \(z_k\) and \(x_k\), and state where each origin sits. (4)
  2. (b) Tabulate the four D–H parameters \((\theta_k, d_k, a_k, \alpha_k)\). Mark which parameter is the joint variable in each row. (3)
  3. (c) Write the three link transformation matrices \({}^{0}T_1\), \({}^{1}T_2\), \({}^{2}T_3\). (3)
  4. (d) Form the arm matrix \({}^{0}T_{\text{tool}}\) to the tool tip (include \(L_t\)) and evaluate it numerically for the values in the table below. Identify \(R\) and \(p\), and verify \(R^{\mathsf T}R = I\). (2)
\(d_1\)\(a_2\)\(a_3\)\(L_t\) \(\theta_1\)\(\theta_2\)\(\theta_3\)
4321\(90^\circ\)\(30^\circ\)\(60^\circ\)

Lengths are in arbitrary consistent units. Note that \(\theta_2+\theta_3\) is a convenient angle here — exploit it.

Note that the two parts' long axes are perpendicular to each other.

Tool-frame convention (as in your notes): \(R = [\,r_1\ r_2\ r_3\,]\) are the tool normal, sliding, and approach vectors; \(r_3\) points the way the tool advances toward the part, \(r_2\) lies along the gripper's closing direction.

  1. (a) Find the arm-matrix value \({}^{0}T_{\text{pick}}\) needed to pick part E from above by grasping its long sides. (4)
  2. (b) Find \({}^{0}T_{\text{place}}\) needed to set part E on top of part F with the centroids aligned and part E's long axis turned to line up with part F's. (3)
  3. (c) Verify that the rotation block of each answer satisfies \(R^{\mathsf T}R = I\) and \(\det R = +1\), and state the rotation that carries your pick orientation to your place orientation. (1)

Section C — predicted extension (5 marks)

Not seen on any recalled Quiz 1 paper, but in the stated scope. Mock 1's Section C covered the tool-configuration vector and a single-solution inverse kinematics; this one deliberately moves to multi-branch inverse kinematics and cubic trajectory interpolation, so that across the two mocks the whole predicted set is exercised. Attempt untimed; a low score here is not a core-topic gap.
  1. C1. Solve the inverse kinematics of the Question 1 arm for position only: given a tool-tip target \((x,y,z)\), find \(\theta_1,\theta_2,\theta_3\). State the reachability condition, and say how many solutions exist and why. Then solve it for the target \(\big(0,\ \tfrac{3\sqrt3}{2},\ \tfrac{17}{2}\big)\) using the Question 1 link lengths, giving every solution exactly. (3)
  2. C2. A single joint must move from \(20^\circ\) to \(80^\circ\) in \(T = 3\,\mathrm{s}\), starting and finishing at zero velocity. Fit a cubic \(q(t) = a t^3 + b t^2 + c t + d\): give \(a,b,c,d\), the value at \(t = T/2\), and the maximum joint rate. (2)
