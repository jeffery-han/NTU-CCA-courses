1 · Q5: Kalman gains for several sensors Exam focus

The picture. Every sensor \(i\) reads the same \(x_k\) plus its own noise. The update pulls the estimate toward each reading by a gain \(L_i\). A quiet sensor (small \(\sigma_i^2\)) deserves a big pull; a noisy one a small pull. The derivation below finds those pulls once, for any number of sensors, so parts (a) and (b) are the same calculation with different variances. HGQ Lec 4 pp. 25–31 (scalar Kalman derivation) · HGQ Lec 4 pp. 33–44 (multiple sensors, sensor integration)

SymbolMeaning
\(x_k,\ \hat x_k\)true value, estimate
\(\tilde x_k = x_k - \hat x_k\)estimation error (tilde = error, hat = estimate)
\(p_k = E[\tilde x_k^2]\)error variance (what we minimise)
\(\sigma_i^2\)noise variance of sensor \(i\): \(a^2, 2a^2, \dots\)
\(c = 1 - \sum_i L_i\)shorthand for what multiplies the old error
\(S = \sum_i 1/\sigma_i^2\)total “information” the group adds

Step 1: error recursion

Each innovation is error plus noise, never estimate plus noise:

$$y_{ik}-\hat x_k = (x_k+v_{ik})-\hat x_k=\tilde x_k+v_{ik}.$$

With \(x_{k+1}=x_k\):

$$\tilde x_{k+1}=x_k-\hat x_k-\sum_i L_i(\tilde x_k+v_{ik})=\Bigl(1-\sum_i L_i\Bigr)\tilde x_k-\sum_i L_i v_{ik}=c\,\tilde x_k-\sum_i L_i v_{ik}.$$

Step 2: variance (every term adds)

Square and take the expectation. Cross terms vanish because \(\tilde x_k\) and the noises are uncorrelated and zero mean. Squaring \(-L_i v_{ik}\) gives \(+L_i^2 v_{ik}^2\), so noise always adds variance:

$$p_{k+1}=c^2p_k+\sum_i L_i^2\sigma_i^2.$$

What you wrote: \(y_{1k}-\hat x_k=\hat x_k+v_1\) and \(P_{k+1}=c^2P_k-\sum L_i^2\sigma_i^2\). A variance can never shrink because noise was added, so a minus sign there is always wrong.

Step 3: set each derivative to zero

\(L_i\) appears in \(c\) (with \(\partial c/\partial L_i=-1\)) and in its own noise term. Keep the \(p_k\) that multiplies \(c^2\):

$$\frac{\partial p_{k+1}}{\partial L_i}=2c(-1)\,p_k+2L_i\sigma_i^2=0\quad\Longrightarrow\quad L_i\sigma_i^2=c\,p_k\ \text{ for every } i.$$

The right side is the same for every sensor, so \(L_i\propto 1/\sigma_i^2\). For Group 1 that already says \(L_1a^2=L_2(2a^2)\), so \(L_2=\tfrac12L_1\).

Step 4: solve for \(c\), then the gains

Sum \(L_i=c\,p_k/\sigma_i^2\) over \(i\): \(1-c=c\,p_kS\), so \(c=\dfrac{1}{1+p_kS}\) and

$$L_i=\frac{p_k}{\sigma_i^2\,(1+p_kS)},\qquad p_{k+1}=c^2p_k(1+p_kS)=c\,p_k\iff\boxed{\frac{1}{p_{k+1}}=\frac{1}{p_k}+S}.$$
