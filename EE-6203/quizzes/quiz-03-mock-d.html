Section A · Multiple choice 12 marks

A1. A unity-feedback loop has open-loop pulse transfer function \(G(z)=\dfrac{0.5(z+0.5)}{(z-0.5)(z-0.2)}\), and the closed loop is stable. The steady-state error to a unit step is

Answer: C

The loop is type 0, so the step error is finite: \(K_p=\lim_{z\to1}G(z)=\frac{0.5(1.5)}{(0.5)(0.8)}=1.875\) and \(e_{ss}=\frac{1}{1+K_p}=\frac{1}{2.875}=0.348\) pp. 186–188. (A) is \(1/K_p\), (B) would need a pole at \(z=1\), (D) is \(K_p/(1+K_p)\), the final output value. (Closed-loop poles \(0.1\pm0.583j\), inside the circle ✓.)

A2. \(G(s)=\dfrac{5(s+3)}{(s+1)(s+2)(s+6)}\) is converted by pole-zero matching into a strictly proper \(G(z)\). How many factors \((z+1)\) appear in the numerator?

Answer: B

\(G(s)\) has \(n-m=3-1=2\) zeros at \(s=\infty\). These map to \(z=-1\), but a strictly proper \(G(z)\) keeps one sample of delay, so it takes \(n-m-1=1\) factor \((z+1)\). A proper result would take \(n-m=2\) pp. 14–15.

A3. Why is \(G(z)\) transformed to the w-plane, \(w=\frac2T\frac{z-1}{z+1}\), before a Bode-based phase-lead design?

Answer: D

On the unit circle \(z=e^{j\omega T}\), so \(G\) is a function of \(e^{j\omega T}\), not a rational function of \(\omega\), and straight-line Bode rules fail. The w-transform maps the unit disc onto the left half w-plane, and \(G(w)\) is rational in the fictitious frequency \(v\) pp. 23–24. (B) is backwards: the w-plane has the same warping, \(v=\frac2T\tan\frac{\omega T}{2}\). The ZOH stays inside \(G(z)\), and the transform does not change stability.

A4. In a one-degree-of-freedom loop, the reference response \(T(z)\) and the disturbance response \(S(z)\) satisfy \(S=1-T\). What does the two-degree-of-freedom structure add?

Answer: A

With one block on the error \(r-y\), choosing \(T\) fixes \(S=1-T\): there is one free function, not two. The 2-DOF form \(U=\gamma\frac{T_c}{R_c}R-\frac{S_c}{R_c}Y\) lets \(R_c,S_c\) place the closed-loop poles (stability, disturbance) while \(T_c,\gamma\) shape the reaction to \(r\) pp. 84–87. Unstable plant zeros still cannot be cancelled in any structure.

Section B · Structured questions 28 marks

B1. (10 marks) A digital gain \(K\) controls a process in a unity-feedback loop. Including one sample of computation delay, the open-loop pulse transfer function is

\[G(z)=\frac{K}{z(z-1)(z-0.5)},\qquad T=0.1\ \text{s}.\]

(a) Use the Jury test to find the range of \(K\) for closed-loop stability. [7]

(b) With \(K=0.2\), find \(K_v\) and the steady-state error to a unit ramp. [3]

Worked solution

(a) \(1+G=0\) gives \(P(z)=z^3-1.5z^2+0.5z+K\), so \(a_0=1,\ a_1=-1.5,\ a_2=0.5,\ a_3=K\). This is third order, so the table row is needed as well pp. 164–166:

  • (1) \(|a_3|\lt a_0\): \(-1\lt K\lt1\).
  • (2) \(P(1)=1-1.5+0.5+K=K\gt0\).
  • (3) \(n\) odd, so \(P(-1)\lt0\): \(-1-1.5-0.5+K=K-3\lt0\) → \(K\lt3\).
  • (4) Row 3 uses \(b_k=a_na_{k+1}-a_0a_{n-1-k}\): \(b_0=a_3a_1-a_0a_2=-1.5K-0.5\) and \(b_2=a_3^2-a_0^2=K^2-1\). The condition is \(|b_2|\gt|b_0|\). With \(0\lt K\lt1\) this reads \(1-K^2\gt1.5K+0.5\), i.e. \(K^2+1.5K-0.5\lt0\), so \(K\lt\frac{-1.5+\sqrt{4.25}}{2}=0.2808\).

Intersection: \(0\lt K\lt0.2808\). Here the table row is the binding condition. Stopping after (1)–(3) gives the wrong answer \(0\lt K\lt1\). Spot check at \(K=0.2\): \(|b_2|=0.96\gt|b_0|=0.8\) ✓.

(b) \(K_v=\frac1T\lim_{z\to1}\frac{z-1}{z}\cdot\frac{K}{z(z-1)(z-0.5)}=\frac{1}{0.1}\cdot\frac{K}{0.5}=20K\) pp. 186–187. At \(K=0.2\) (stable ✓): \(K_v=4\), \(e_{ss}=0.25\).

Common slips: using \(P(-1)\gt0\) (the even-\(n\) rule); stopping at \(K\lt1\) without building the \(b\) row; mixing up the \(b_k\) index order (the \(z^0\) column of row 3 is \(b_{n-1}=b_2\)).

B2. (8 marks) An analog lead controller \(D(s)=\dfrac{4(s+2)}{s+8}\) is to be implemented with \(T=0.1\) s.

(a) Find \(D(z)\) by the bilinear transformation in the form \(K_d\dfrac{z-z_0}{z-p_0}\). [3]

(b) Find the pole-zero matched \(D(z)=\alpha\dfrac{z-z_1}{z-p_1}\) with the DC gain matched. Give \(\alpha\). [2]

(c) Write the direct-programming difference equation for your answer to (a), with input \(e(k)\) and output \(u(k)\). If \(e(k)=1\) for \(k\ge0\) (and 0 before), find \(u(0)\) and \(u(1)\). [3]

Worked solution

(a) \(\frac2T=20\), \(s=20\frac{z-1}{z+1}\) pp. 7–8. Then \(s+2=\frac{22z-18}{z+1}\) and \(s+8=\frac{28z-12}{z+1}\), and the \((z+1)\) cancels:

\[D(z)=\frac{4(22z-18)}{28z-12}=\frac{22z-18}{7z-3}=\frac{22}{7}\cdot\frac{z-0.8182}{z-0.4286}.\]

\(K_d=3.143\), \(z_0=0.8182\), \(p_0=0.4286\). DC check: \(D(1)=\frac{4}{4}=1=D(s{=}0)=\frac{4\cdot2}{8}\) ✓.

(b) \(z_1=e^{-0.2}=0.8187\), \(p_1=e^{-0.8}=0.4493\). Since \(n=m\) there is no zero at infinity, so no \((z+1)\) factor pp. 14–15. DC: \(\alpha\frac{1-0.8187}{1-0.4493}=1\), so \(\alpha=\frac{0.5507}{0.1813}=3.038\).

(c) Divide by \(7z\): \(D=\dfrac{\frac{22}{7}-\frac{18}{7}z^{-1}}{1-\frac37z^{-1}}\). Direct programming pp. 104–107:

\[u(k)=\tfrac37u(k-1)+\tfrac{22}{7}e(k)-\tfrac{18}{7}e(k-1).\]

\(u(0)=\frac{22}{7}=\mathbf{3.143}\). \(u(1)=\frac37\cdot\frac{22}{7}+\frac{22}{7}-\frac{18}{7}=\frac{66}{49}+\frac{28}{49}=\frac{94}{49}=\mathbf{1.918}\). (It decays toward the DC gain 1, the lead "kick" you expect.)

Common slips: writing \(-\frac37u(k-1)\) (the denominator sign must flip); using \(2/T=2\); adding a \((z+1)\) in (b) even though \(n=m\).

B3. (10 marks) A unity-feedback loop has a digital controller \(C(z)\) in front of

\[G_{ZAS}(z)=\frac{0.25(z+0.8)}{(z-1)(z-0.5)}.\]

The reference is a unit step.

(a) Show that \(G_{cl}(z)=z^{-1}\) satisfies the design conditions, and find \(C(z)\). [3]

(b) For the design in (a), find the control signal \(u(k)\) for \(k=0,\dots,3\). Explain what happens to the continuous output between samples. [3]

(c) Design a ripple-free controller using \(G_{cl}(z)=Kz^{-1}(1+0.8z^{-1})\). Find \(K\) and \(C(z)\), and give \(y(1)\) and \(u(0)\). [4]

Worked solution

(a) Check the four conditions pp. 51–56:

  1. Relative degree: the plant's is 1, and \(z^{-1}\)'s is 1 ✓.
  2. The plant zero \(-0.8\) is inside the circle ✓.
  3. The pole at \(z=1\) is marginal; \(1-z^{-1}=\frac{z-1}{z}\) contains it ✓.
  4. \(G_{cl}(1)=1\) ✓.
\[C=\frac{1}{G_{ZAS}}\cdot\frac{z^{-1}}{1-z^{-1}}=\frac{(z-1)(z-0.5)}{0.25(z+0.8)}\cdot\frac{1}{z-1}=\mathbf{\frac{4(z-0.5)}{z+0.8}}.\]

The plant already has an integrator, so \(C\) needs none.

(b) \(U=\dfrac{G_{cl}}{G_{ZAS}}R=\dfrac{4(z-0.5)}{z+0.8}\), so \(u=4,\ -5.2,\ 4.16,\ -3.328,\dots\), i.e. \(u(k)=-5.2(-0.8)^{k-1}\) for \(k\ge1\). \(C\) cancels the plant zero at \(-0.8\), so \(u\) keeps alternating and only decays slowly. The samples give \(y(k)=1\) for \(k\ge1\), but the continuous output ripples between samples (Example 5.8 pp. 66–67).

(c) Ripple-free means \(G_{cl}\) keeps all plant zeros, so that \(u\) settles in finitely many steps pp. 73–77. From \(G_{cl}(1)=K(1+0.8)=1\), \(K=1/1.8=5/9=0.5556\). Then

\[1-G_{cl}=\frac{z^2-\frac59z-\frac49}{z^2}=\frac{(z-1)(z+\frac49)}{z^2},\qquad C=\frac{G_{cl}}{G_{ZAS}(1-G_{cl})}=\mathbf{\frac{20}{9}\cdot\frac{z-0.5}{z+0.4444}}.\]

\(Y=G_{cl}R\) gives \(y=0,\ \tfrac59,\ 1,\ 1\), so \(y(1)=0.5556\). \(U=\frac{G_{cl}}{G_{ZAS}}R=\frac{20}{9}(1-0.5z^{-1})\) gives \(u=\tfrac{20}{9},\ -\tfrac{10}{9},\ 0,\ 0\), so \(u(0)=2.222\). \(u\) reaches 0 (the plant integrator holds \(y=1\)), so there is no ripple. The cost is one extra sample to settle, and a gentler control signal.

Common slips: \(K=1/0.8\) (the condition is \(G_{cl}(1)=K(1+0.8)=1\)); saying (a) is ripple-free because \(y(k)=1\) at the samples; adding an integrator to \(C\) for a type-1 plant.
