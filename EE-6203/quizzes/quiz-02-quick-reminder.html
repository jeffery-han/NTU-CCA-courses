Q1 · Modelling recipes

  • ODE: divide by the leading coefficient first. With \(x_1=y,\ x_2=\dot y\): \[\ddot y+a_1\dot y+a_0y=bu\ \Rightarrow\ \mathbf A=\begin{bmatrix}0&1\\-a_0&-a_1\end{bmatrix},\ \mathbf B=\begin{bmatrix}0\\b\end{bmatrix},\ \mathbf C=[1\ \ 0].\]
  • Block diagram: one state at each integrator / first-order block output. A block \(\frac{k}{s+a}\) with input \(v\) and output \(x\) gives \(\dot x=-ax+kv\). Write each block's input as a sum of states and \(u\), then read off the rows.
  • TF: \(G(s)=\mathbf C(s\mathbf I-\mathbf A)^{-1}\mathbf B+D=\dfrac{\mathbf C\,\operatorname{adj}(s\mathbf I-\mathbf A)\,\mathbf B}{\det(s\mathbf I-\mathbf A)}+D\). Cross-check against the ODE.

Q2 · ZOH discretisation

\[\mathbf\Phi(t)=\mathcal L^{-1}\{(s\mathbf I-\mathbf A)^{-1}\}\] \[\mathbf x(k+1)=\mathbf\Phi(T)\mathbf x(k)+\mathbf\Theta(T)u(k),\quad \mathbf\Theta(T)=\Big[\int_0^T\mathbf\Phi(\tau)\,d\tau\Big]\mathbf B\]

\(\mathbf C\) and \(D\) are unchanged. Discrete TF: \(G(z)=\mathbf C(z\mathbf I-\mathbf\Phi)^{-1}\mathbf\Theta+D\). Discrete poles are \(z=e^{\lambda T}\).

Shortcut (supplementary, not on the slides): if \(\mathbf A\) is invertible, \(\mathbf\Theta=\mathbf A^{-1}(\mathbf\Phi-\mathbf I)\mathbf B\). If \(\mathbf A\) has a zero eigenvalue (a motor), integrate directly.

Inverse Laplace pairs you will use

\[\tfrac1s\to1,\quad \tfrac1{s^2}\to t,\quad \tfrac1{s+a}\to e^{-at}\] \[\tfrac1{s(s+a)}\to\tfrac{1-e^{-at}}{a},\qquad \tfrac1{(s+a)(s+b)}\to\tfrac{e^{-at}-e^{-bt}}{b-a}\] \[\int_0^T e^{-a\tau}d\tau=\tfrac{1-e^{-aT}}{a}\]

2×2 inverse: \(\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1}=\dfrac1{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}\).

Controllability / observability

\[\mathbf W_C=[\mathbf B\ \ \mathbf A\mathbf B],\qquad \mathbf W_O=\begin{bmatrix}\mathbf C\\\mathbf C\mathbf A\end{bmatrix}\quad(n=2)\]

The property holds iff the rank is \(n\); for 2×2 this means \(\det\ne0\). On the discrete model, use \(\mathbf\Phi,\mathbf\Theta\), not \(\mathbf A,\mathbf B\).

With a parameter: solve \(\det\mathbf W_C=0\) for the bad values and state "controllable iff \(\beta\ne\dots\)".

Sampling an oscillator with \(\omega T=k\pi\) loses controllability/observability. A pole–zero cancellation in the TF means the realisation is uncontrollable or unobservable.

Q3 · State transition

\[\mathbf x(k+1)=\mathbf A\mathbf x(k)+\mathbf Bu(k)\]

Just iterate step by step; it is faster and safer than the closed form:

\[\mathbf x(k)=\mathbf A^k\mathbf x(0)+\sum_{i=0}^{k-1}\mathbf A^{k-1-i}\mathbf Bu(i)\]

With feedback \(u=-\mathbf K\mathbf x\): \(\mathbf x(k+1)=(\mathbf A-\mathbf B\mathbf K)\mathbf x(k)\).

Q3 · Deadbeat / pole placement

Goal: \(\det(z\mathbf I-\mathbf A+\mathbf B\mathbf K)=\alpha_C(z)\); deadbeat means \(\alpha_C(z)=z^n\).

\[\mathbf K=[0\ \cdots\ 0\ \ 1]\,\mathbf W_C^{-1}\,\alpha_C(\mathbf A)\quad\text{(Ackermann)}\] \[\text{Deadbeat, }n=2:\ \ \mathbf K=[0\ \ 1]\,\mathbf W_C^{-1}\mathbf A^2\]

For \(\mathbf W_C=\begin{bmatrix}a&b\\c&d\end{bmatrix}\), the last row of \(\mathbf W_C^{-1}\) is \(\frac1{ad-bc}[-c\ \ a]\).

Alternative (also accepted): coefficient matching. Expand \(\det(z\mathbf I-\mathbf A+\mathbf B\mathbf K)\) with \(\mathbf K=[k_1\ k_2]\) and set it equal to \(z^2\).

Check: \(\mathbf A-\mathbf B\mathbf K\) has trace 0 and det 0; then \(\mathbf x(2)=\mathbf 0\) from any \(\mathbf x(0)\).

Canonical forms (Lect 2)

For \(G=\dfrac{b_1z+b_0}{z^2+a_1z+a_0}\):

\[\text{CCF: }\mathbf A=\begin{bmatrix}0&1\\-a_0&-a_1\end{bmatrix},\ \mathbf B=\begin{bmatrix}0\\1\end{bmatrix},\ \mathbf C=[b_0\ \ b_1]\]

OCF: \(\mathbf A_O=\mathbf A_C^{\mathsf T},\ \mathbf B_O=\mathbf C_C^{\mathsf T},\ \mathbf C_O=[0\ \ 1]\).

In CCF, the gain is \(k_{i+1}=\alpha_i-a_i\). Similarity \(\mathbf x=\mathbf P\mathbf w\): \(\mathbf P^{-1}\mathbf A\mathbf P,\ \mathbf P^{-1}\mathbf B,\ \mathbf C\mathbf P\). State feedback does not move the zeros.

Common mistakes

  • Not normalising the ODE (getting 8 where the answer is 2).
  • Forgetting the \(\mathbf B\) in \(\mathbf\Theta\), or integrating \(\mathbf\Phi\) at \(t=T\) instead of over \([0,T]\).
  • Testing controllability with the continuous \(\mathbf A,\mathbf B\) when the question asks about the sampled system.
  • Writing \(\mathbf W_O\) as columns: it stacks rows.
  • Using \(\mathbf A+\mathbf B\mathbf K\) when the convention is \(u=-\mathbf K\mathbf x\).
  • Sign slips in \(\operatorname{adj}\); always verify \(\mathbf A-\mathbf B\mathbf K\) at the end.
