The question

A voltage source \(e(t)\) drives a series loop of a resistor \(R = 4\,\Omega\), an inductor \(L = 1\) H and a capacitor \(C = \tfrac13\) F. The output is the capacitor voltage, \(y = v_C\). Using the states \(x_1 = v_C\) and \(x_2 = i\) (the loop current), derive the state-space model \(\dot{\mathbf x} = \mathbf A\mathbf x + \mathbf B e,\; y = \mathbf C\mathbf x\).

Part 1

Voltage and current: push and flow

Picture water in pipes:

  • Voltage (volts, V) is the pressure, the push that drives charge round.
  • Current \(i\) (amperes, A) is the flow, the amount of charge passing per second.
  • A voltage source \(e(t)\) is a pump. It is the input we control.

Every component "uses up" part of the pump's pressure. That used-up amount is the component's voltage drop.

Part 2

The three components and their rules

PartAnalogyRuleIn words
Resistor \(R\)Narrow, rough pipe\(v_R = R\,i\) More flow means more pressure lost to friction.
Inductor \(L\)Heavy water wheel\(v_L = L\,\dfrac{di}{dt}\) It fights changes in flow. Speeding the flow up takes pressure.
Capacitor \(C\)Tank filling up\(i = C\,\dfrac{dv_C}{dt}\) Flow into the tank raises its level (its voltage).
Why are \(v_C\) and \(i\) the states?

A state is something the system remembers: you cannot change it instantly. A tank's level cannot jump (filling takes time), so \(v_C\) is a state. A heavy wheel's speed cannot jump either, so the inductor current \(i\) is a state. The resistor has no memory, so it adds no state. Rule of thumb: one state per capacitor (its voltage) and one per inductor (its current).

Common pitfall

The capacitor rule gives the current in terms of \(dv_C/dt\). We want \(\dot v_C\) on its own, so we divide by \(C\): \(\dot v_C = i / C\). Dividing by \(C = \tfrac13\) means multiplying by 3.

Check

Which component's rule involves \(\dfrac{di}{dt}\)?

Part 3

The loop law (KVL) and "series"

Kirchhoff's Voltage Law: once round a closed loop, the pressure the pump supplies equals the sum of the drops. Think of it as a budget: the source supplies \(e\) volts and the parts spend all of it.

\[ e = v_R + v_L + v_C \]

Series means one single path, so the same current \(i\) flows through all three parts. That's why a single \(i\) appears in every rule.

Check

Suppose \(e = 10\) V and at some instant \(v_R = 3\) V and \(v_C = 5\) V. What is \(v_L\) (in volts)?

Part 4

The derivation, one step at a time

Goal: write \(\dot x_1\) and \(\dot x_2\) using only \(x_1, x_2\) and the input \(e\), with no other variables left over.

Step 1: the capacitor rule gives \(\dot x_1\).
Why start here? \(x_1 = v_C\), and the capacitor rule is the one that contains \(\dot v_C\).

\[ i = C\,\dot v_C \;\Rightarrow\; \dot v_C = \frac{1}{C}\,i \;\Rightarrow\; \dot x_1 = \frac{1}{1/3}\,x_2 = 3x_2 \]

Step 2: KVL, with each drop replaced by its rule.
Why? \(x_2 = i\), and \(\dot i\) appears only in the inductor's rule, which sits inside KVL.

\[ e = \underbrace{R\,i}_{v_R} + \underbrace{L\,\dot i}_{v_L} + v_C \]

Step 3: solve for \(\dot i\). Move everything except \(L\dot i\) to the left, then divide by \(L\).

\[ \dot i = \frac{1}{L}\big(e - R\,i - v_C\big) \]

Step 4: plug in the numbers \(R = 4\), \(L = 1\), and rename \(v_C = x_1\), \(i = x_2\).

\[ \dot x_2 = -x_1 - 4x_2 + e \]

Step 5: pack both equations into matrices. Each row of \(\mathbf A\) holds the coefficients of \(x_1, x_2\) in one equation, and \(\mathbf B\) holds the coefficient of \(e\).

\[ \begin{aligned} \dot x_1 &= \;\;0\cdot x_1 + 3\,x_2 + 0\cdot e\\ \dot x_2 &= -1\cdot x_1 - 4\,x_2 + 1\cdot e \end{aligned} \] \[ \dot{\mathbf x} = \underbrace{\begin{bmatrix} 0 & 3 \\ -1 & -4 \end{bmatrix}}_{\mathbf A}\mathbf x + \underbrace{\begin{bmatrix} 0 \\ 1 \end{bmatrix}}_{\mathbf B} e, \qquad y = \underbrace{\begin{bmatrix} 1 & 0 \end{bmatrix}}_{\mathbf C}\mathbf x \]

The output is \(y = v_C = x_1\), so \(\mathbf C\) just picks the first state.

Part 5

Does the answer make physical sense?

Steady state. With a constant input \(e\), the system eventually stops changing, so both derivatives are zero:

  • \(\dot x_1 = 3x_2 = 0\) gives \(i = 0\): the current stops.
  • \(\dot x_2 = -x_1 - 4x_2 + e = 0\) gives \(v_C = e\): the capacitor charges to the source voltage.

That's right physically: a full tank holds back the pump, so no more water flows.

Stability. \(\det(s\mathbf I - \mathbf A) = s^2 + 4s + 3 = (s+1)(s+3)\). Both poles are negative, so the system is stable. This matches the general series-RLC formula \(s^2 + \tfrac{R}{L}s + \tfrac{1}{LC}\).

See it. Below, \(e\) jumps from 0 to 1 V at \(t = 0\), with \(L = 1\) and \(C = \tfrac13\). Drag \(R\):

\(x_1 = v_C\) (V) \(x_2 = i\) (A)

Small \(R\) makes \(v_C\) overshoot and wobble (the wheel's momentum carries the flow past the target). Large \(R\) makes it creep up slowly. Either way it settles at \(v_C = 1 = e\).

Check

The source is held at a constant \(e = 6\) V for a long time. What is \(v_C\) (in volts)?

Recap

Final answer

\[ \mathbf A = \begin{bmatrix} 0 & 3 \\ -1 & -4 \end{bmatrix},\quad \mathbf B = \begin{bmatrix} 0 \\ 1 \end{bmatrix},\quad \mathbf C = \begin{bmatrix} 1 & 0 \end{bmatrix} \]

Recipe for any circuit like this

  1. States = capacitor voltages and inductor currents.
  2. Capacitor: \(\dot v_C = i_C / C\).
  3. Inductor: \(\dot i_L = v_L / L\), with \(v_L\) taken from KVL round the loop.
  4. Substitute until only states and inputs remain, then read off the coefficients into \(\mathbf A\), \(\mathbf B\), \(\mathbf C\).
  5. Check: steady state (\(\dot{\mathbf x} = 0\)) should give \(v_C = e\) and \(i = 0\).
