English for this question. Natural phrasing: "How do you derive the transfer function from the state-space model?" or "How is \(G(s)\) obtained from \(\mathbf A,\mathbf B,\mathbf C,D\)?"
Vocabulary: transfer function (传递函数), state-space model (状态空间模型), determinant (行列式), adjugate (伴随矩阵), characteristic polynomial (特征多项式), pulse transfer function = the discrete-time TF \(G(z)\). Use "derive / obtain / compute" a transfer function, not "calculate out".

1 · What a transfer function is

A transfer function is the ratio output transform ÷ input transform, with all initial conditions set to zero:

\[G(s)=\frac{Y(s)}{U(s)}\bigg|_{\text{zero initial conditions}}.\]

Why zero initial conditions? A TF describes how the system responds to the input alone. Stored initial energy would add a term that does not depend on \(U(s)\), so the ratio \(Y/U\) would not be a fixed function of \(s\).

The tool that makes this work is the Laplace transform rule

\[\mathcal L\{\dot x(t)\}=sX(s)-x(0)\ \xrightarrow{\ x(0)=0\ }\ sX(s),\]

so "differentiate" becomes "multiply by \(s\)", and differential equations become algebra.

Simplest example. \(\dot x=-2x+u,\ y=x\). Transform: \(sX=-2X+U\Rightarrow (s+2)X=U\Rightarrow G(s)=\dfrac{1}{s+2}\).

2 · The general formula \(G(s)=\mathbf C(s\mathbf I-\mathbf A)^{-1}\mathbf B+D\)

Do exactly what Part 1 did, but with vectors. Start from

\[\dot{\mathbf x}=\mathbf A\mathbf x+\mathbf Bu,\qquad y=\mathbf C\mathbf x+Du.\]
  1. Laplace transform (zero initial state): \(s\mathbf X(s)=\mathbf A\mathbf X(s)+\mathbf BU(s)\).
  2. Collect \(\mathbf X\) on the left: \(s\mathbf X-\mathbf A\mathbf X=\mathbf BU\Rightarrow (s\mathbf I-\mathbf A)\mathbf X=\mathbf BU\).

    Why \(s\mathbf I\) and not \(s\)? You cannot subtract a matrix from a scalar. Writing \(s\mathbf X=s\mathbf I\mathbf X\) lets you factor out \(\mathbf X\) on the right.

  3. Solve for the state: \(\mathbf X(s)=(s\mathbf I-\mathbf A)^{-1}\mathbf BU(s)\). (Multiply on the left by the inverse: matrix order matters.)
  4. Substitute into the output equation: \(Y=\mathbf C\mathbf X+DU=\big[\mathbf C(s\mathbf I-\mathbf A)^{-1}\mathbf B+D\big]U\).
\[G(s)=\frac{Y(s)}{U(s)}=\mathbf C(s\mathbf I-\mathbf A)^{-1}\mathbf B+D=\frac{\mathbf C\,\operatorname{adj}(s\mathbf I-\mathbf A)\,\mathbf B}{\det(s\mathbf I-\mathbf A)}+D.\]

Size check for a single-input single-output system with \(n\) states: \((1\times n)(n\times n)(n\times1)=1\times1\), a scalar. ✓
The denominator \(\det(s\mathbf I-\mathbf A)\) is the characteristic polynomial, so the poles of \(G(s)\) are the eigenvalues of \(\mathbf A\) (unless a pole cancels with a zero).

3 · The 2×2 toolkit (all you need in the quiz)

For \(\mathbf M=\begin{bmatrix}a&b\\c&d\end{bmatrix}\):

\[\det\mathbf M=ad-bc,\qquad \operatorname{adj}\mathbf M=\begin{bmatrix}d&-b\\-c&a\end{bmatrix}\ \ (\text{swap the diagonal, negate the off-diagonal}),\qquad \mathbf M^{-1}=\frac{\operatorname{adj}\mathbf M}{\det\mathbf M}.\]

Shortcut that saves time: \(\mathbf C\) and \(\mathbf B\) usually contain zeros, so you rarely need the whole adjugate.

  • \(\mathbf C=[1\ \ 0]\) keeps row 1 of the adjugate; \(\mathbf C=[0\ \ 1]\) keeps row 2.
  • \(\mathbf B=[0\ \ b]^{\mathsf T}\) keeps column 2 (times \(b\)); \(\mathbf B=[b\ \ 0]^{\mathsf T}\) keeps column 1.
  • So \(\mathbf C=[1\ 0]\), \(\mathbf B=[0\ b]^{\mathsf T}\) means: numerator \(=b\times\) entry (1,2) of the adjugate \(=b\times(-\text{entry (1,2) of } s\mathbf I-\mathbf A)\).

4 · Worked: Test A Q1(iii), continuous \(G(s)\)

Model (i): RLC circuit

\[\mathbf A=\begin{bmatrix}0&3\\-1&-4\end{bmatrix},\quad \mathbf B=\begin{bmatrix}0\\1\end{bmatrix},\quad \mathbf C=\begin{bmatrix}1&0\end{bmatrix},\quad D=0.\]
  1. \(s\mathbf I-\mathbf A=\begin{bmatrix}s&-3\\1&s+4\end{bmatrix}\) (subtract \(\mathbf A\) from \(s\) on the diagonal, negate the rest).
  2. \(\det(s\mathbf I-\mathbf A)=s(s+4)-(-3)(1)=s^2+4s+3=(s+1)(s+3)\).
  3. \(\operatorname{adj}(s\mathbf I-\mathbf A)=\begin{bmatrix}s+4&3\\-1&s\end{bmatrix}\).
  4. Numerator: \(\mathbf C\) picks row 1 \(=[s+4\ \ 3]\); times \(\mathbf B=[0\ 1]^{\mathsf T}\) picks the second entry: \(3\).
\[G(s)=\frac{Y(s)}{E(s)}=\frac{3}{s^2+4s+3}=\frac{3}{(s+1)(s+3)}.\]

Model (ii): block diagram

\[\mathbf A=\begin{bmatrix}0&1\\-3&-4\end{bmatrix},\quad \mathbf B=\begin{bmatrix}0\\3\end{bmatrix},\quad \mathbf C=\begin{bmatrix}1&0\end{bmatrix}.\]

\(s\mathbf I-\mathbf A=\begin{bmatrix}s&-1\\3&s+4\end{bmatrix}\), \(\det=s^2+4s+3\), \(\operatorname{adj}=\begin{bmatrix}s+4&1\\-3&s\end{bmatrix}\). Row 1 \(\cdot\,[0\ 3]^{\mathsf T}=1\cdot3=3\). Same \(G(s)\).

Two independent ways to check

  • Circuit (voltage divider with impedances \(R,\ Ls,\ \tfrac1{Cs}\)): \(\dfrac{V_C}{E}=\dfrac{1/(Cs)}{R+Ls+1/(Cs)}=\dfrac{1}{LCs^2+RCs+1}=\dfrac{1}{\tfrac13s^2+\tfrac43s+1}=\dfrac{3}{s^2+4s+3}\). ✓
  • Block algebra for unity negative feedback around \(F(s)=\dfrac{3}{s+4}\cdot\dfrac1s\): \(\dfrac{F}{1+F}=\dfrac{3}{s(s+4)+3}=\dfrac{3}{s^2+4s+3}\). ✓
  • DC gain: \(G(0)=1\): at steady state the capacitor charges to the full source voltage. ✓
Pitfalls
  • Writing \(\mathbf A-s\mathbf I\): the sign of every entry flips and the numerator sign goes wrong.
  • Forgetting to negate the off-diagonal in the adjugate.
  • Expanding the whole \(2\times2\) inverse when \(\mathbf C\) and \(\mathbf B\) only need one entry.

5 · Discrete time: the pulse transfer function \(G(z)\)

Same derivation with the z-transform. The rule \(\mathcal Z\{x(k+1)\}=zX(z)-zx(0)\) becomes \(zX(z)\) with zero initial state, so "shift forward" becomes "multiply by \(z\)":

\[\mathbf x(k+1)=\mathbf\Phi\mathbf x(k)+\mathbf\Theta u(k)\ \Rightarrow\ z\mathbf X=\mathbf\Phi\mathbf X+\mathbf\Theta U\ \Rightarrow\ \mathbf X=(z\mathbf I-\mathbf\Phi)^{-1}\mathbf\Theta U.\]
\[G(z)=\frac{Y(z)}{U(z)}=\mathbf C(z\mathbf I-\mathbf\Phi)^{-1}\mathbf\Theta+D.\]

It is the continuous formula with \(s\to z\), \(\mathbf A\to\mathbf\Phi\), \(\mathbf B\to\mathbf\Theta\). The 2×2 toolkit of Part 3 applies unchanged.

Worked: Test A Q2(iii), route 1 (formula)

\[\mathbf\Phi=\begin{bmatrix}0.6065&0\\0.2387&0.3679\end{bmatrix},\quad \mathbf\Theta=\begin{bmatrix}0.3935\\0.0774\end{bmatrix},\quad \mathbf C=\begin{bmatrix}0&1\end{bmatrix}.\]
  1. \(z\mathbf I-\mathbf\Phi=\begin{bmatrix}z-0.6065&0\\-0.2387&z-0.3679\end{bmatrix}\), \(\det=(z-0.6065)(z-0.3679)\) (triangular: product of the diagonal).
  2. \(\operatorname{adj}=\begin{bmatrix}z-0.3679&0\\0.2387&z-0.6065\end{bmatrix}\).
  3. \(\mathbf C=[0\ 1]\) picks row 2 \(=[0.2387\ \ z-0.6065]\). Dot it with \(\mathbf\Theta\) (both entries are non-zero, so both count): \[0.2387(0.3935)+(z-0.6065)(0.0774)=0.0939+0.0774z-0.0469.\]
\[G(z)=\frac{0.0774\,z+0.0470}{(z-0.6065)(z-0.3679)},\qquad \text{poles } e^{-0.5},\ e^{-1};\ \text{zero }\approx-0.607.\]

Route 2 (transform table): \(G(z)=(1-z^{-1})\,\mathcal Z\!\left\{\dfrac{G(s)}{s}\right\}\)

This route starts from the continuous TF. The \((1-z^{-1})\) and the \(\tfrac1s\) come from the zero-order hold: its transfer function is \(\dfrac{1-e^{-sT}}{s}\), and \(e^{-sT}\leftrightarrow z^{-1}\).

  1. Continuous TF by Part 2: \(\det(s\mathbf I-\mathbf A)=(s+1)(s+2)\); \(\mathbf C=[0\ 1]\) and \(\mathbf B=[1\ 0]^{\mathsf T}\) pick adjugate entry (2,1) \(=1\). So \(G(s)=\dfrac{1}{(s+1)(s+2)}\).
  2. Partial fractions (cover-up): \(\dfrac{G(s)}{s}=\dfrac{1}{s(s+1)(s+2)}=\dfrac{1/2}{s}-\dfrac{1}{s+1}+\dfrac{1/2}{s+2}\).
  3. Table \(\big(\tfrac1s\to\tfrac{z}{z-1},\ \tfrac1{s+a}\to\tfrac{z}{z-e^{-aT}}\big)\), then multiply by \(1-z^{-1}=\tfrac{z-1}{z}\): \[G(z)=\tfrac12-\frac{z-1}{z-e^{-T}}+\tfrac12\,\frac{z-1}{z-e^{-2T}}.\]
  4. Over the common denominator \((z-a)(z-b)\), \(a=e^{-0.5},\ b=e^{-1}\): the \(z^2\) terms cancel \(\big(\tfrac12-1+\tfrac12=0\big)\), the \(z\) coefficient is \(\tfrac12+\tfrac b2-a=0.0774\), and the constant is \(\tfrac{ab}{2}+\tfrac a2-b=0.0470\). Same \(G(z)\). ✓

Which route in the quiz? If the question says "by formula" or you already have \(\mathbf\Phi,\mathbf\Theta\), use route 1: it reuses your work and avoids partial fractions. Route 2 is a good independent check. Quick check either way: \(G(1)=\dfrac{0.1244}{0.3935\times0.6321}=0.5=G(s)\big|_{s=0}\). A ZOH keeps the DC gain.

Pitfalls
  • Using \(\mathbf A,\mathbf B\) in the discrete formula: it must be \(\mathbf\Phi,\mathbf\Theta\).
  • Using \(\mathbf C=[1\ 0]\) out of habit: read the output equation.
  • Dropping one product when \(\mathbf\Theta\) has two non-zero entries.
  • Quoting the continuous poles \(-1,-2\) as discrete poles; discrete poles are \(e^{sT}\).

6 · Recap: the method to remember

ContinuousDiscrete
Formula\(\mathbf C(s\mathbf I-\mathbf A)^{-1}\mathbf B+D\)\(\mathbf C(z\mathbf I-\mathbf\Phi)^{-1}\mathbf\Theta+D\)
Denominator\(\det(s\mathbf I-\mathbf A)\)\(\det(z\mathbf I-\mathbf\Phi)\)
Poleseigenvalues of \(\mathbf A\)eigenvalues of \(\mathbf\Phi\) \(=e^{\lambda T}\)
DC gain check\(G(0)\)\(G(1)\) (equals \(G(0)\) under ZOH)
  1. Form \(s\mathbf I-\mathbf A\) (or \(z\mathbf I-\mathbf\Phi\)).
  2. Determinant → denominator.
  3. Adjugate: swap diagonal, negate off-diagonal.
  4. \(\mathbf C\) picks rows, \(\mathbf B\)/\(\mathbf\Theta\) picks columns → numerator.
  5. Add \(D\); check the DC gain or a second route.
